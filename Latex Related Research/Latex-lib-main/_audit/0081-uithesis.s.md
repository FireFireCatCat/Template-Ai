## Overclaims (do not change the verdict)
1. Gloss not in the source: the file says `uithesis-makara-kuning.png` is "the alternative logo for `\setmakaraimage`" (file line 127). uithesis-doc.dtx:1556 only says both images must be on the TeX search path; `\setmakaraimage` (doc:552-558) never names it, and grep finds "kuning" only at doc:1556 and :1569.
2. Doc contradicts the file's TikZ row and the file does not say so: uithesis-doc.dtx:257 lists `tikz` as "Vector graphics (cover page layout)" and :258 `tikzpagenodes` as "TikZ page node anchors". The code draws nothing (grep above), so the file's "load-only, nothing is ART" is right, but the doc's claim should be quoted and dismissed in the file.
3. Missing from the map and from the load-only list: `\RequirePackage{changepage}` + `\strictpagecheck` (dtx:441-442). grep finds no `adjustwidth`, `\checkoddpage` or `\ifoddpage` anywhere in either `.dtx`, so it is load-only; the lib has `page.adjustwidth` for it. The file says the map was "checked by grep" for load-only packages, which this one escaped.
4. Class-internal redefinitions left out of the "recorded, not counted" list, same BESPOKE/class kind as the two listed: `\renewcommand{\newglossaryentry}` and `\renewcommand{\newacronym}` as entry counters (dtx:2073-2084, feeding the two-run `UI@prev@count@glossary`, dtx:4103); `\pretocmd{\@chapter}{...}` (dtx:4016); `\def\@chapter` and `\renewcommand\chapter` for the journal (dtx:905-924); the `\renewcommand\chapter` auto-clear wrapper (dtx:1379-1389); `\let\include\input` (dtx:988-990); `\renewcommand{\clearpage}` (dtx:1326, mentioned only as "journal helpers"); `\let\@writefile`, `\let\addcontentsline` (dtx:2049-2052, covered by the 1898-2098 range).
5. Reductions marked "yes" that are not real reductions: the journal `\RenewDocumentCommand{\section}{s o m}` wrapper (dtx:949-984) adds `\par\nopagebreak[4]`, `\phantomsection` and TOC entries for starred sections; `head.titlesec` does not express that, so "head.kernel or head.titlesec" (file line 111) is a hand-written program. The same goes for `\makefrontmatter` ("yes, for a fixed choice", file line 115): it is reducible only by writing the resolved pages by hand. The file can say this safely because the whole class is published; if the class were zip-local these would be BESPOKE.
6. The `\twocolumn` command (dtx:3124) and the `\onecolumn`/`\twocolumn` switch in `UIfullwidthpages` (dtx:1081-1088) are mapped to `cols.twocolumn-option`; lib v2 has `cols.twocolumn-cmd` for exactly this (the analyst read v1).
7. `font.mathptmx` for `pslatex` (dtx:423): the lib line lists `mathptmx`/`times`/`tgtermes`/`txfonts`, not `pslatex`. The file says "the package is the parameter", a stretch but harmless.
8. `EXTERNAL/package` call on `glossaries-extra[automake]` (dtx:576): it is loaded unconditionally in the default monograph format and asks for shell escape. The file calls it "soft failure". The pilot ruling in the rubric names "shell escape", but its reason is "does not compile without the tool", and `idx.glossaries` is an untagged lib way that needs `makeglossaries` anyway, so I do not count it. A reviewer who reads the ruling literally would.
