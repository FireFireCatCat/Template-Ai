# 0108-lix: LiX thesis class (thesis.cls over the lix.sty meta-package)

- Unverified: read from the source, not compiled.
- Source: Source/0108-lix/ (origin: https://latextemplates.com/downloads/lix.zip; licence: GPL-3.0)
- Kind: thesis
- Lib: v0
- Engine: pdfLaTeX-compatible (needs a 2022+ kernel for `\NewCommandCopy` and `\AddToHook`; `\includesvg` would also need Inkscape and shell escape, but only if an `.svg` is included, see Content-opaque)
- Main file: main.tex (other samples: none)
- Read: main yes, zip-local classes and styles all (thesis.cls 86 lines, lix.sty 1149 lines, both read in full; references.bib is data)

## Verdict
yes. `thesis.cls` is `class.article` with `11pt, titlepage` plus the `lix` meta-package, and every `lix` command is either a bundle of published packages or a thin alias over them. The only conditionals test whether a field (title, author, abstract...) was given, so they flatten per document, and the two edits to kernel internals (`\@seccntformat`, a `cmd/section/before` hook) reduce to a `titlesec` label and a `\clearpage`. Four ways are proposed as new (`sp.penalties`, `sp.lettrine`, `color.transparent`, `front.doclicense`), the last three only for lix features the sample never calls. Weakest points, both recorded and neither blocking: the `.svg` branch of `\fig` and the unconfirmed `\numberless` level in `\titlespacing`.

## Blockers
none

## Class setting
- Class: `class.article` options: `11pt, titlepage` (thesis.cls:10); every user option is forwarded to article (thesis.cls:8-9). The zip-local class `thesis` is only the wrapper (reduction below).
- Class-native vocabulary used: article's `\section`, `\subsection`, `\tableofcontents`, `\maketitle`, `\cite`, `\TeX` (main.tex:13-29). Zip-local vocabulary, all aliases that store a value or call published commands: `\subtitle`, `\keywords`, `\abstract{}`, `\toc`, `\bib{}` (main.tex:4,6,7,13,29; lix.sty:257,269,196,146,844).
- Active lix options: algorithms, basics, code, figures, formatting, headings, license, lists, math, metadata, publish, refs, size, tables (thesis.cls:13). Dead for this class, because `thesis` forwards options to article only and a second `\usepackage[..]{lix}` would clash: cover (lix.sty:324-387), header (424-436), isbn (553-560), periodical (636-652), sign (773-793), ornaments (1093-1143, pgfornament TikZ), stdclass (1060-1091). The book-like branch of `\h..\hhhh` (473-537) is dead too, because article has no `\chapter`.

## Content-opaque
- `.svg` import in `\fig` (lix.sty:391,404-406): the `svg` package calls Inkscape through shell escape when an `.svg` is included. Judged as artwork preparation, not template look: the emitter ships PDF or PNG and uses `fig.graphicx`. Not exercised by the sample (it has no figure). A stricter reader could call it `EXTERNAL`; I did not, because the figure wrapper, caption and width rule are fully covered.
- `\EANBarcode` and `GS1` (lix.sty:382,554,726) and the pgfornament TikZ page frames (lix.sty:1093-1143): only reachable through the dead options `cover`, `isbn`, `ornaments`; not template looks for this class.
- references.bib:1-7 (bibliographic data); the sample's text and `\TeX{}` (main.tex:15-27).

## Lib changes
- New ways proposed:
  - `NEW:sp.penalties`: `\widowpenalties`, `\widowpenalty`, `\clubpenalty`, `\brokenpenalty`; pdfLaTeX (e-TeX primitive and kernel parameters). W1: documented TeX/e-TeX primitives and kernel parameters. W2: integer values. W3: widow and orphan control is asked for by many templates. W4: one preamble line. `sp.lengths` is described as lengths, which is why this is not folded into it.
  - `NEW:sp.lettrine`: package `lettrine` (CTAN), drop caps; pdfLaTeX. W1: CTAN package. W2: lines, lhang, loversize, findent, nindent, options as values. W3: any template with a decorated first letter. W4: `\lettrine[opts]{X}{rest}` around the first word.
  - `NEW:color.transparent`: package `transparent` (CTAN), `\transparent{opacity}`; pdfLaTeX. W1: CTAN. W2: one opacity value. W3: any overlay or tint. W4: a body wrapper or a preamble-time setting inside an overlay.
  - `NEW:front.doclicense`: package `doclicense` (CTAN), licence text and icon; pdfLaTeX. W1: CTAN. W2: type, modifier, version, holder as values. W3: any template with a licence or copyright page. W4: `\usepackage[type=,modifier=,version=]{doclicense}` + `\doclicenseLongText`, `\doclicenseIcon` on a copyright page.
- Mapping notes (no new way): `tabularray` is grouped under `tbl.nicematrix`, whose lib row already holds the alternative table engine `tabu`; `esint` is grouped under `math.amssymb` as a symbol-font package; `silence` and `numspell` are not ways (non-visual, and spelled-out text is content). If the consolidator wants a separate id for tabularray or esint, rows `tbl.nicematrix` and `math.amssymb` here are the ones to retag.
- Existing ways used for the first time by the lib: none needed (the consolidator computes this)
