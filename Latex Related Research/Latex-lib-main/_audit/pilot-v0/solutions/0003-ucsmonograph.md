## Lib changes
- New ways proposed:
  - `NEW:class.ucsmonograph`: class `ucsmonograph`, engine pdf. W1 CTAN macros/latex/contrib/ucsmonograph, LPPL 1.3c, in TeX Live and MiKTeX, public PDF manual; W2 options (`12pt`, `oneside|twoside`, babel languages, `lmodern`, `cite=alf|num`, `siglas`, `simbolos`) and key-value commands (`\titulo`, `\autor`, ...); W3 serves any UCS/ABNT monograph, not one document (same kind of way as `class.acmart`); W4 `\documentclass[...]{ucsmonograph}` plus body wrappers of its own commands. Profile: front matter `\imprimircapa \imprimirfolhaderosto \imprimirfolhadeaprovacao`, `resumo`, `dedicatoria`, `epigrafe`, `quadro`.
  - `NEW:class.abntex2`: class `abntex2` (abnTeX2 bundle, CTAN, LPPL 1.3, engine pdf). W1 CTAN; W2 class options (`chapter=TITLE`, `section=TITLE`, `openright`, `a4paper`) and `\ABNTEX*font` hooks; W3 any ABNT document; W4 `\documentclass[...]{abntex2}`. Used here only in the peel test (the emitter loads it through `class.ucsmonograph`); any zip that loads it directly would use it as a way.
  - `NEW:bib.abntex2cite`: package `abntex2cite` from the abnTeX2 bundle (CTAN, engine pdf). W1 published, documented on CTAN; W2 options `alf|num`, `abnt-etal-list`, `abnt-etal-text`, `abnt-full-initials`, `\citebrackets`; W3 serves any ABNT bibliography; W4 `\usepackage[...]{abntex2cite}` plus `\bibliography`. Grepped `bib\.` in the lib: `bib.apacite` names apacite/chicago/harvard/jurabib and `bib.natbib` names natbib, neither names this package, so it has no home.
  - `NEW:math.icomma`: package `icomma` (CTAN, engine pdf). W1 published; W2 loaded with no options (a decimal comma that is also a list separator is its whole behaviour, so W2 is met only trivially); W3 any document with decimal commas; W4 one `\usepackage{icomma}` line. Grepped `math\.` in the lib: `math.physics` lists physics/braket/cancel/nccmath/empheq, not this package.
- Existing ways used for the first time by the lib: none needed (the consolidator computes this)
