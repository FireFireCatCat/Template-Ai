- Unverified: read from the source, not compiled.
- Source: Source/0018-fhj-script/ (origin: https://mirrors.ctan.org/macros/latex/contrib/fhj-script.zip; licence: lppl1.3)
- Kind: thesis (fhjbook, "mainly the master thesis", README.md:25-26; fhjpaper is a short two-column paper class, journal-like)
- Lib: v0
- Engine: pdfLaTeX-compatible (KOMA-Script, babel, hyperref, scrlayer-scrpage; no fontspec, no unicode-math; the logos are PDF files)
- Main file: fhjbook.dtx (ltxdoc documentation driver at fhjbook.dtx:31-41; other samples: fhjcommon.dtx:26-36, fhjpaper.dtx:31-40). The zip holds no thesis or paper `.tex` that uses the classes, and no generated `.cls`/`.sty`. The template is the class code inside the three `.dtx` files, generated by `fhj-script.ins:46-48`.
- Read: main yes, zip-local classes and styles all (as `.dtx` sources, every line of the three files read; no `.cls`/`.sty` file is present). Not read: the three compiled documentation PDFs (they typeset the same `.dtx`). Read: the logo PDF `fhjInformaticsLogo.en.img.pdf` (a vector image asset). The German logo was not opened.

## Verdict
yes. Everything the three `.dtx` files define reduces to published ways: `scrbook` and `scrartcl` with class options, `scrlayer-scrpage`, `hyperref`, hand-laid title, abstract and declaration pages, small kernel-level exercise blocks, and (for the author block) `authblk`. The zip-local macros are data holders, string aliases and language or gender conditionals that an emitter resolves per document, plus one author-list routine that `authblk` expresses with parameters. No custom output routine, no box-and-glue algorithm, no template-defining artwork. Confidence is moderate, not high: nothing is compiled, and the `authblk` and `titling` reductions in fhjpaper are a look-equivalent, not a proven identical output (see Bespoke code row 12).

## Blockers
none

## Class setting
- Class: `class.scrbook` options: a4paper, DIV=14, BCOR=10mm (fhjbook.dtx:87); extra options are forwarded unchanged to scrbook (fhjbook.dtx:70-71). This is fhjbook reduced to its base class.
- Class: `class.scrartcl` options: a4paper, twocolumn, fontsize=9pt, DIV=16 (fhjpaper.dtx:89); extra options forwarded (fhjpaper.dtx:73-74). This is fhjpaper reduced to its base class.
- The bundle's own `class.fhjbook` and `class.fhjpaper` are themselves released on CTAN with public documentation (origin URL, fhjbook.pdf, fhjpaper.pdf), so each is also a way on its own. The verdict does not rely on that: every construct is reduced below.
- Documentation drivers use `class.ltxdoc` (fhjbook.dtx:32, fhjcommon.dtx:27, fhjpaper.dtx:32). That is how the package is documented, not the template, and it is out of scope.
- Class-native vocabulary used (class.fhjbook): `\FHJProgram{code}` (via fhjcommon), `\title` (redefined, fhjbook.dtx:210), `\subtitle` (232), `\author`, `\authorinfo{m|f|o}{matnr}{cohort}` (238), `\supervisor{name}{gender}` (246), `\cosupervisor` (254), `\date`, `\FHJLocation` (271), `\FHJAbstractDE/EN{text}{kw1,kw2}` (404, 409), `\FHJMakeTitlePage` (331), `\FHJMakeDeclaration` (fhjcommon.dtx:303), `\FHJMakeAbstract` (430), `\FHJThesisFrontMatter` (457), plus KOMA `\frontmatter`, `\mainmatter`, `\chapter` (fhjbook.dtx:307-317, 477-481).
- Class-native vocabulary used (class.fhjpaper): `\title` (fhjpaper.dtx:134), `\shorttitle` (144), `\authorsnames[superscripts]{names}` (247), `\authorsaffiliations{{affil},{affil}}` (258), `\maketitle` (via `\@maketitle`, 375), `\FHJProgram`.
- Class-native vocabulary (fhjcommon, any class): `\FHJProgram`, `\FHJProgramLong/Short[code]`, `\FHJDefineProgram` (fhjcommon.dtx:106-190), `\FHJExHeader[type]{id}{topic}` (350), `\FHJExHeaderScheduled` (374), `\FHJExExample[points]{title}` (405), `\FHJExLLM` (430), `\FHJClassAbbr/Term/Lecturer` (327-329), `\FHJExampleFigDE/EN`, `\FHJExampleTabDE/EN` (456-522).
