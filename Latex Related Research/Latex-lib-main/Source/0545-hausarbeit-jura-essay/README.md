# Hausarbeit Jura Essay

A German legal essay starter using `hausarbeit-jura`. The class supplies a
formal title page, juridical section numbering, generous margin notes and a
book-like structure suited to a German law term paper.

The example is original German prose on proportionality and automated public
administration. Replace the title-page metadata and write the body under the
provided chapter/section structure. The class also supports its `jurabib`
bibliography workflow when you need footnote citations.

`hausarbeit-jura.cls` is supplied by TeX Live and is not bundled here. The
upstream class is released under LPPL-1.3c or later:
https://ctan.org/pkg/hausarbeit-jura

## Build

    pdflatex main
