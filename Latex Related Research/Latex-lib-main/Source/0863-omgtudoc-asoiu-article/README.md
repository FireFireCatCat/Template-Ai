# omgtudoc-asoiu article starter

This Russian-language starter uses the `omgtudoc-asoiu` class in its minimal
document mode. It is suitable for an ASOIU course project or technical paper
and demonstrates the class's typography, numbered sections, mathematics, and
table layout.

The class and its support files are supplied by the pinned TeX distribution and
are not bundled in the download. The upstream class is LPPL 1.3c or later:
<https://ctan.org/pkg/omgtudoc-asoiu>.

Compile with LuaLaTeX (XeLaTeX is also supported by the upstream class).
