# Arubertoson resume and cover letter

A matched, restrained resume and cover-letter pair inspired by the
Arubertoson lead. Both documents share the same typographic tokens and
synthetic applicant details.

## Build

```sh
pdflatex main.tex
pdflatex cover_letter.tex
```

The upstream project is MIT-licensed. This starter contains no upstream
personal content or bundled assets.
