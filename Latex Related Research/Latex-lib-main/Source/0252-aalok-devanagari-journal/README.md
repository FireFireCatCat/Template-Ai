# Aalok Marathi journal starter

This XeLaTeX starter follows the section rhythm of the Marathi journal
`Aalok`: title and author information, a bilingual abstract, keywords,
numbered sections, a data table, and a short conclusion. It deliberately
uses a small self-contained article shell so that the example does not bundle
the upstream journal's fonts, banking details, or institutional artwork.

The upstream Aalok class code is GPL-3.0-or-later together with the Aalok
copyleft notice; the upstream documentation alone is GFDL. This archive does
not redistribute the class or documentation. Replace the neutral shell with
the current official class workflow when preparing an actual submission.

Source: https://ctan.org/pkg/aalok
