# Research Diary Template (Klassen)

An original daily research-diary starter following the older Overleaf
`research-diary-template` entry associated with Klassen. It has weekly goals,
dated entries, a literature note, experiment status, and a next-week review.

Compile with PDFLaTeX. The older gallery entry has unresolved licence and
asset provenance in the research record, so this is a warning-only catalogue
entry; no upstream files, logos, or personal data are included.

Source: https://www.overleaf.com/latex/templates/research-diary-template/txzdtvgpjhsv
