# Contract starter

This starter demonstrates the CTAN `contract` package for formalised legal
documents: a contract environment, numbered clauses, subclauses, and a simple
signature block. The text is fictional and is not legal advice; replace it
with terms reviewed for your jurisdiction.

Source: <https://ctan.org/pkg/contract>
