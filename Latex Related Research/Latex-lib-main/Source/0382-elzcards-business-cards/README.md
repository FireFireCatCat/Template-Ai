# elzcards Business Cards

A print-ready business-card starter using the `elzcards` package. One front and one back design are imposed at the package's standard 3.5in by 2in business-card size, with visible crop lines and a restrained two-colour layout.

The package is provided by TeX Live and is not bundled here. It is maintained by Emilio Augusto Lazo Zaia and its upstream source grants redistribution and modification under the LaTeX Project Public License 1.3c or any later version:

- Source: <https://ctan.org/pkg/elzcards>
- Engine: pdfLaTeX

Compile with `just package elzcards` from the catalogue root.
