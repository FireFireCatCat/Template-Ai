# TEMat article

This Spanish-language starter follows the public TEMat article workflow for
the electronic journal of the Asociación Nacional de Estudiantes de
Matemáticas. It includes bilingual metadata, an abstract, theorem-ready
mathematics, examples, a table, and appendices while keeping the source
portable with the standard `article` class.

The Overleaf source identifies itself as CC BY 4.0. The downloaded archive
includes the required attribution notice. Confirm the journal's current style
and submission instructions before use.
