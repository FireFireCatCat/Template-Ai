# Kalender German Year Calendar

This starter demonstrates the CTAN `kalender` package, which generates a
complete German year calendar from `\Kalender{<year>}`. Change the year in
`main.tex` and compile with pdfLaTeX.

The upstream `kalender.sty` is included because CTAN identifies this legacy
package as unavailable in standard TeX Live installations. Its licence status
is not stated clearly in the package metadata; treat that as a provenance and
licence warning and verify permission before redistribution.
