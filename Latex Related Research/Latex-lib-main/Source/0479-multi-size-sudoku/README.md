# Multi-size Sudoku

This starter uses the CTAN `multi-sudoku` package to create hand-editable
Sudoku grids from 1x1 through 49x49.  The example places a compact 4x4 puzzle
beside a standard 9x9 puzzle and shows the package's row and sub-grid rules.

Edit the entries in `main.tex` using `&` between cells, `\nl` after an ordinary
row, and `\NL` after a row that precedes a thicker sub-grid rule.  The package
is provided by TeX Live and is not copied into this archive.

Source: <https://ctan.org/pkg/multi-sudoku>
