\noindent The `Scrabble` package provides a standalone board and an
environment that overlays words. Coordinates start at the south-west cell;
use the optional `V` argument for a vertical word.

\begin{center}
  \begin{EnvScrabble}[Scale=0.43,Labels=false,Help]
    \ScrabblePutWord{LATEX}{1,13}
    \ScrabblePutWord[V]{TEX}{3,15}
    \ScrabblePutWord{CODE}{5,11}
    \ScrabblePutWord[V]{STYLE}{8,8}
    \ScrabblePutWord{PUZZLE}{7,5}
    \ScrabblePutWord[V]{GRID}{12,6}
  \end{EnvScrabble}
\end{center}

\section*{Inline example}
The same package can place a word in running text:
\ScrabbleWord[Lang=EN,Scale=0.55]{TEX}.
Use `*` for a blank tile and change `Lang` to `FR`, `DE`, or `ES` when you
want localized tile labels and scoring.
