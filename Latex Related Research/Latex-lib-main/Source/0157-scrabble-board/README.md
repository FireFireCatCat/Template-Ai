# Scrabble board

This starter uses Cédric Pierquet's CTAN `Scrabble` package to draw an English
board, place horizontal and vertical words, and show the package's inline
word command.  `Scrabble.sty` is included because it is not present in the
pinned TeX image; it retains the upstream LPPL header.

The name Scrabble and related marks are trademarks of Hasbro and Mattel.  This
archive is a typesetting demonstration, not an endorsement or a game product.
Replace the example words with material you are entitled to publish.
