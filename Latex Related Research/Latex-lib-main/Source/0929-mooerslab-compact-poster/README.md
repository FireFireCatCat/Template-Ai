# MooersLab compact poster

A compact, image-forward scientific poster starter inspired by the MooersLab
`posterInLaTeX` lead. It is an original starter with synthetic content, a
large finding panel, and a readable two-column research narrative.

Edit the title, authors, result callout, and section text in `main.tex`.

## Build

```sh
lualatex main.tex
```
