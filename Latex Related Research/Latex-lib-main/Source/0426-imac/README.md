# IMAC

LaTeX style and template for the [International Modal Analysis
Conference (IMAC)](https://www.sem.org/imac).

The IMAC Package for generating International Modal Analysis
Conference formatted papers in LaTeX. As of the 2026-10-07 release,
the formatting (fonts, page layout, heading style, and citation style)
matches the official IMAC Word Template distributed in the
conference's Author Toolkit, so LaTeX and Word submissions produce
consistent results.

All documentation can be found in the file `imac.pdf`, generated by
`imac.tex`.

## Files

- `imac.sty` -- the package itself; put this on your `$TEXINPUTS`
  (or in the same directory as your document) and load it with
  `\usepackage{imac}`.
- `imac.bst` -- the BibTeX style file for IMAC-format bibliographies;
  needed alongside `imac.sty` if you use BibTeX.
- `imac.tex` -- an example/template document showing how to use the
  package, and the source of the `imac.pdf` documentation.
- `imac.bib` -- a sample bibliography used by the example document.
- `imac.dtx` / `imac.ins` -- the docstrip sources that generate
  `imac.sty` (and this documentation); most users do not need these
  directly unless building the package from source.

## Installation

Manual install: copy `imac.sty` and `imac.bst` into the same
directory as your `.tex` document, or into a directory on your
`TEXMFHOME` tree (e.g. `~/texmf/tex/latex/imac/` and
`~/texmf/bibtex/bst/imac/`), then run `texhash`/`mktexlsr` if
needed.

If building from the `.dtx`/`.ins` sources instead, run:

```
latex imac.ins
```

which will extract `imac.sty`.

## Requirements

`imac.sty` requires the following standard LaTeX packages, all of
which are part of any complete TeX distribution (e.g. TeX Live,
MiKTeX): `ifthen`, `amsmath`, `cite`, `mathptmx`, and `geometry`.
