# PoetryTeX

An original small anthology starter using the `poetrytex` package. It demonstrates reusable title metadata, a dedication, a table of contents, a list of poems, poem groups, poems with subtitles, centered poems, and annotation sections.

The package is provided by TeX Live and is not bundled here. PoetryTeX is maintained by Sam Whited and its upstream README grants redistribution and modification under the LaTeX Project Public License 1.3c or any later version:

- Source: <https://ctan.org/pkg/poetrytex>
- Engine: pdfLaTeX

Compile with `just package poetrytex` from the catalogue root.
