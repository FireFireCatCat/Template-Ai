# SJTUTeX report

An English Shanghai Jiao Tong-style report starter using the installed
`sjtureport` class. It demonstrates the class's title metadata, chapters,
equations, tables, and appendix structure with original systems-engineering
prose.

SJTUTeX's source code is LPPL 1.3c. The university badge used by the installed
class is owned by Shanghai Jiao Tong University and is not bundled here; the
PDF may therefore carry the class's institutional branding when compiled with
an installation that provides it. Source and licence:
https://github.com/sjtug/SJTUTeX

Compile with XeLaTeX. The class is supplied by TeX Live.
