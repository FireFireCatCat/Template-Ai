# bookcover starter

This starter uses the CTAN `bookcover` class to produce a complete wraparound
paperback cover with front, spine, back, bleed, trim marks, and editable
typographic components. The colours and copy are original placeholders.

Upstream source: https://ctan.org/pkg/bookcover

Upstream licence: LPPL-1.2-or-later, as stated in the class header. The class
is supplied by TeX Live and is not bundled in this download.
