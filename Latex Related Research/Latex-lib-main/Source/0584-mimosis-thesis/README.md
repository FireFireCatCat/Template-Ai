# Mimosis Thesis

A minimal, modern thesis template (bachelor's, master's or doctoral) from
`github:Pseudomanifold/latex-mimosis` by Bastian Rieck, MIT licence (see
`LICENSE.md`).

## Files

- `main.tex` — start here (upstream `Thesis.tex`).
- `mimosis.cls` — the class, vendored.
- `Sources/` — title page, abstract and chapters; add your own `\include`s.
- `Thesis.bib` — bibliography (biblatex + biber).

Compiles with pdfLaTeX; XeLaTeX or LuaLaTeX also work and use the nicer fonts.
