# Electronic Journal of Probability

This starter uses the ejpecp class in EJP mode for an article in the
Electronic Journal of Probability. It demonstrates the journal metadata
macros, MSC classification, abstract and keyword block, theorem environments,
and the class's plain BibTeX bibliography workflow.

The CTAN package is released under LPPL 1.2 or later by the EJP/ECP
contributors. The class is supplied by the pinned TeX environment and is not
bundled here. Set the ECP class option when preparing an article for the
Electronic Communications in Probability instead.

Source: https://ctan.org/pkg/ejpecp
