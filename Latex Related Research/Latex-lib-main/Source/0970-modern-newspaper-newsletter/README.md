# Modern newspaper newsletter starter

This Unicode-first starter uses the CTAN `modernnewspaper` package for issue
metadata, a masthead, article commands, drop caps, and configurable news
columns. It is suitable for multilingual bulletins and small newspapers.

Upstream source: https://github.com/Laitei40/modernnewspaper

Upstream licence: LPPL-1.3c. A small catalogue adaptation is bundled because
the pinned build image lacks the upstream package's optional Devanagari,
Myanmar, and CJK fonts; its documented interfaces are unchanged.
