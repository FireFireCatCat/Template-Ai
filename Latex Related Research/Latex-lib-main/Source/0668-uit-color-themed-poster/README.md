# UiT Color-Themed Poster

This LuaLaTeX starter captures the reusable portrait-poster idea from the UiT
color-themed poster template: a strong institutional-style header, modular
blocks, a compact figure, and a results table. The document is written with
synthetic content and uses TeX Live fonts and packages only.

Upstream reference: <https://github.com/uit-cosmo/poster-template>

The upstream repository is marked MIT and identifies separately licensed OFL
fonts. This catalogue starter does not bundle upstream theme files, fonts,
logos, or example artwork. The palette is configurable and should not be
treated as an official UiT mark.

Compile with LuaLaTeX.
