# Per Musi

An original Portuguese/English starter following the Per Musi Overleaf
template: bilingual title metadata, double-blind review fields, abstracts,
keywords, section headings, a music-analysis example, and references. The
gallery source uses the custom `permusi` class and `anonymize` package; those
files are not independently downloadable, so this package uses standard
LaTeX with equivalent author-facing structure and no publisher branding.

The gallery lists the source as CC BY 4.0 by Flávio Schiavoni and Thiago
Campolina. Retain that attribution when adapting the starter and check Per
Musi's current author instructions before submission.

Compile with XeLaTeX.
