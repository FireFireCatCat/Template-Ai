# ReScience C article

An original compact starter for a ReScience C computational-replication
manuscript. `metadata.tex` holds the submission metadata, while `main.tex`
contains the article body, a reproducibility checklist table, and a real
resolved bibliography entry.

The upstream repository licenses the non-font template files GPL-3-or-later;
the bundled fonts carry their own Apache or SIL Open Font License notices. The
corresponding texts are retained in `COPYING` and the font directories.
