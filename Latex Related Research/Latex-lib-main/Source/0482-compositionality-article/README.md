# Compositionality article

An original one-column research-article starter for the
`compositionalityarticle` class. It demonstrates author metadata, a structured
abstract, equations, a native TikZ figure, and a linked reference.

The class is redistributed under LPPL-1.3c. The class is from the
[Compositionality template repository](https://github.com/Compositionality/compositionality-latex-template);
see `LICENSE` for the upstream licence text. The starter prose and figure are
original to this catalogue.
