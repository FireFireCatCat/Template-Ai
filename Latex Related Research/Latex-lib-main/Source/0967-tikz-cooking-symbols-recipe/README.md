# TikZ cooking symbols recipe starter

This vector recipe-card starter uses the CTAN `tikz-cookingsymbols` package
for scalable oven, grill, air-fryer, and pizza symbols. Optional arguments
control symbol scale and colour; replace the sample cards with your own.

Upstream source: https://ctan.org/pkg/tikz-cookingsymbols

Upstream licence: LPPL-1.3c. The package is supplied by TeX Live and is not
bundled in this download.
