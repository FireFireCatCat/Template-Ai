# Plantilla para un artículo LaTeX

This Spanish-language article starter is based on the Overleaf template
“Plantilla para un artículo LaTeX” by Steph Migoni. It demonstrates a useful
undergraduate-physics article structure: title matter, abstract, figures,
tables, equations, lists, cross-references, comments, and a BibTeX
bibliography.

The example prose and figures in this catalogue starter are original. The
upstream project references a sample photograph that is not included here, so
the figure example uses a portable drawn placeholder instead. No publisher or
institutional branding is bundled.

The upstream gallery lists the template as CC BY 4.0. See `ATTRIBUTION.txt`
in the downloaded archive for the required credit.

Source: <https://www.overleaf.com/latex/templates/plantilla-para-un-articulo-latex/ycmrsxnswcct>

Compile with PDFLaTeX.
