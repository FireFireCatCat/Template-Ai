# Flowfram newsletter starter

This starter demonstrates the CTAN `flowfram` layout engine with a flowing
main article frame and a fixed sidebar. Define additional frames to turn the
same skeleton into a brochure, bulletin, or magazine spread.

Upstream source: https://ctan.org/pkg/flowfram
