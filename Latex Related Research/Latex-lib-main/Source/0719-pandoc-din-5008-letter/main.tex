\opening{Dear Alex Morgan,}

Thank you for your request for the quarterly footfall dataset. We can provide
the anonymised daily totals for the period from January through June 2026.
The accompanying data dictionary explains the aggregation window, missing
day codes and the suppression rule applied to very small counts.

The release does not include raw device identifiers or precise timestamps.
Those fields are not needed for the evaluation question described in your
request, and removing them reduces the chance that an individual journey can
be inferred. We would be happy to discuss a more detailed release if you can
specify a research purpose and an appropriate review process.

Please confirm the preferred secure transfer address by 30 September. We
will then send the dataset and checksum in a separate message.

\closing{Yours sincerely,}
