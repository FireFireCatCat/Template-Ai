# Markdown to Book KDP

A directly compilable book starter based on [vpuna/markdown-to-book](https://github.com/vpuna/markdown-to-book), an MIT-licensed Pandoc/XeLaTeX workflow for paperback and hardcover KDP output. The upstream project exposes trim-size, gutter, and Markdown chapter workflows; this catalogue document demonstrates the LaTeX side without bundling upstream scripts, samples, or fonts.

Edit the metadata and chapters below, or use the same geometry in a Pandoc-generated document. Compile with XeLaTeX when adding Unicode text or a custom OpenType font.
