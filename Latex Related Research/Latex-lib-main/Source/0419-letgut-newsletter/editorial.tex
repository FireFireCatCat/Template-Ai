\section{Éditorial}

Bienvenue dans ce numéro consacré aux petits outils qui rendent une chaîne de
publication plus fiable. Nous suivons le même principe qu'un bon script de
composition : une source courte, des dépendances explicites et un résultat que
l'on peut relire avant de le partager.

\begin{itemize}
  \item noter les versions des outils ;
  \item conserver les sources et les crédits avec le numéro ;
  \item vérifier la sortie PDF sur un écran et sur papier.
\end{itemize}
