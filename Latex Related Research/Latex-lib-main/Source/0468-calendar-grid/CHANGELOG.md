## 1.0.0 — 2026-10-06

### Added

- Deterministic proleptic Gregorian date validation, leap-year, month-length, and weekday calculations.
- Fixed six-week and compact month grids with all seven week-start choices and configurable adjacent or blank overflow.
- Twelve-month year overviews with configurable column count.
- Per-date event notes, inclusive named date ranges, localized label lists, cell dimensions, and day/month-title formatting hooks.
- l3build regression suite and English user guide source.
