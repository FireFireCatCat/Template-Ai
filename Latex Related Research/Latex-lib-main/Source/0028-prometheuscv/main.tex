% PATCHED: upstream selected Cormorant Garamond by FAMILY NAME
% ("Cormorant Garamond Regular" etc), which fontspec resolves through
% fontconfig. This pinned image's fontconfig only registers 14 base families
% (DejaVu/URW/Nimbus/etc) — it does NOT scan TeX Live's own font tree, so a
% family-name lookup for anything else silently falls back to nullfont: the
% document compiles with zero errors and every character renders as a
% "Missing character" warning in the log, i.e. a blank page. Confirmed with
% a minimal `\setmainfont{Lato}` reproduction. kpathsea, unlike fontconfig,
% DOES resolve TeX Live's own font tree, and fontspec accepts an exact
% filename in place of a family name to force that lookup path — Cormorant
% Garamond ships in TeX Live as texmf-dist/fonts/truetype/catharsis/
% cormorantgaramond/*.ttf, so loading by filename below renders real glyphs
% (verified against the rendered preview, not just a clean compile).
\setmainfont[
	BoldFont=CormorantGaramond-Bold.ttf,
	ItalicFont=CormorantGaramond-Italic.ttf,
	BoldItalicFont=CormorantGaramond-BoldItalic.ttf
]{CormorantGaramond-Regular.ttf}						% Set the main font to Comorant Garamond (https://github.com/CatharsisFonts/Cormorant)
