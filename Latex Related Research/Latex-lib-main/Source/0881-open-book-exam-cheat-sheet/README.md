# Open-Book Exam Cheat Sheet

An A4-landscape, seven-column XeLaTeX starter for dense, searchable exam
reference sheets. It follows the compact layout and colour-coded command
pattern documented by the upstream project, while the example content is an
original data-analysis reference sheet.

Compile with XeLaTeX. The template uses DejaVu Sans, which is available in the
pinned build image; replace it with another installed font if desired.

Upstream reference: https://github.com/Purestone/chitshit
