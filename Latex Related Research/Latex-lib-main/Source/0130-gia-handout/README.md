**A LaTeX class for GI publications**

The class `gia-handout` provides a layout for publications of the Gesellschaft für Informatik e.V. (GI), following its corporate design.

---

## Contents

- `gia-handout.cls`
- `gia-handout-doc.tex`
- `gia-default-frontcover.pdf`
- `gia-default-backcover.pdf`

---

## Installation

Copy `gia-handout.cls` into your local TeX tree.

---

## Usage

```latex
\documentclass{gia-handout}
```

See the documentation for details.
