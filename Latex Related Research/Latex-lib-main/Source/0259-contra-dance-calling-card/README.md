# Contra dance calling card

A calling-card starter using the `contracard` class. It demonstrates the
`contra` environment, phrase boundaries, move counts, and named dance moves.

The class is supplied by TeX Live, so it is not bundled. The dance title and
instructions are original starter content; replace them with your own set.

Build with PDFLaTeX:

    pdflatex main

Source: https://ctan.org/pkg/contracard
