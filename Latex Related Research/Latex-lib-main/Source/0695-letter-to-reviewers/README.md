# Letter to Reviewers

This is a portable, original starter based on the [letter-2-reviewers LaTeX
template](https://github.com/cdc08x/letter-2-reviewers-LaTeX-template) by
cdc08x, licensed GPL-3.0. It demonstrates a cover note, reviewer sections,
boxed comments, and visually distinct author responses. The upstream helper
files and example manuscript are not bundled; this catalogue starter keeps
the response workflow self-contained.

Replace the fictional manuscript metadata and comment/response pairs in
`main.tex`. Compile with PDFLaTeX. The GPL licence applies to redistribution
of this starter.
