# Shahriar-Labs assignment starter

An original assignment sheet with point-valued questions, work areas, and a marking checklist, reflecting the coursework use case of the upstream collection.

Source lead: <https://github.com/shihabshahrier/Latex_Templates>

The repository is reported as MIT with upstream exceptions whose per-directory terms were not independently verified. No upstream assets, personal data, logos, or prose are bundled. Compile with PDFLaTeX.
