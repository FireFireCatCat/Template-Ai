# ECNU homework

A bilingual-friendly homework starter based on the homework portion of the
ECNU LaTeX template collection. It demonstrates a cover header, mathematical
notation, algorithm-style steps, and a worked solution in a XeLaTeX document.

Upstream: <https://github.com/zhzhwz/latexTemplates>

The upstream repository identifies the collection as GPL-3.0 licensed. This
catalogue starter is original and does not bundle the repository's class,
figures, or lab-report materials.

Compile with `xelatex`.
