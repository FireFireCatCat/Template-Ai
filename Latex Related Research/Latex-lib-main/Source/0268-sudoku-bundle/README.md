# Sudoku bundle worksheet

This starter demonstrates the three-package CTAN Sudoku bundle: `printsudoku`
renders a puzzle file, and `solvesudoku` prints the puzzle followed by the
solution found by its built-in solver.  The included `puzzle.sud` is a small
plain-text puzzle file with nine rows of digits and dots.

Replace the nine puzzle rows in `puzzle.sud`, then compile `main.tex`.  The
bundle also provides `createsudoku` for generating puzzle files; it is
available in TeX Live even though this starter keeps generation separate from
the printable worksheet.

Source: <https://ctan.org/pkg/sudokubundle>
