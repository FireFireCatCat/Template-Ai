# Cookybooky

An original recipe-book starter inspired by the `cookybooky` package by Jürgen
Gilg. It keeps the package's focus on a structured ingredient list, numbered
preparation steps, serving metadata, and a polished page, using a small local
recipe macro that is easy to extend.

Upstream source: https://ctan.org/pkg/cookybooky
