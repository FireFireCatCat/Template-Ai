# Book of Abstracts

A self-contained conference abstract booklet starter based on the [Overleaf
Book-of-Abstracts template](https://www.overleaf.com/latex/templates/book-of-abstracts/vxxsznnfjzzj).
The upstream page identifies the template as CC BY 4.0; the distributed archive
includes generated attribution. No upstream logos, fonts, or class files are
bundled.

Edit the `abstractentry` calls in `main.tex` and compile with PDFLaTeX.
