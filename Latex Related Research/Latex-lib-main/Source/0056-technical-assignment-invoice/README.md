# Technical Assignment Invoice

A simpleinvoice-style invoice starter for a paid technical assignment. It
shows how to present a fixed assignment fee, findings handover, due date, tax
treatment, and bank details in a small practical document.

Compile with PDFLaTeX. The pinned TeX image provides the `simpleinvoice`
package; it is used but not bundled in this archive.

Upstream reference: https://www.overleaf.com/latex/templates/technical-assignment-invoice/mknndvrrbfqf

Upstream author: Philip Trauner. The gallery identifies the work as using an
adapted simpleinvoice library but does not expose a standard licence. This
starter uses fictional content and does not bundle the adapted library,
employer identity, logo, or personal data.
