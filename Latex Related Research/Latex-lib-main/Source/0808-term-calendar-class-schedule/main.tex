% One \calday per weekday column; \skipday advances the internal date
% without printing a column, used here to skip weekends. \caltexton{N}{...}
% attaches text to the Nth day printed by the environment (1-indexed across
% the whole term, not per week) -- but ONLY for days where \classday was
% executed via \calday[..]{\classday}: \caltexton ultimately keys off
% \ifclassday, which is false by default, and silently prints nothing (no
% error, no warning) if you forget it on every \calday call. Learned this by
% shipping a first draft with correctly-aligned but completely empty boxes.
