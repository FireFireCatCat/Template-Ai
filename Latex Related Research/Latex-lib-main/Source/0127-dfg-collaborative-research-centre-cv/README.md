# DFG Collaborative Research Centre CV

An original LuaLaTeX CV/profile starter based on the CTAN [dfg-crc package](https://ctan.org/pkg/dfg-crc).
The package supports DFG Collaborative Research Centre proposals and CV
sections and is LPPL 1.3c licensed. This portable example keeps the CV fields
independent of institutional logos and proposal-specific assets; it is not
published, endorsed, or maintained by the DFG.
