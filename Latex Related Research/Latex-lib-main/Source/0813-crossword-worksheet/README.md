# Crossword puzzle worksheet

An editable crossword worksheet starter based on the CTAN `crossword` package's
grid-and-clue workflow. The example keeps the puzzle data in the document so a
reader can replace the grid, clues, and answer key without external assets.

Compile with PDFLaTeX. The grid is drawn with ordinary LaTeX tables in this
starter, which keeps the example portable while preserving the upstream
worksheet's central idea.

Upstream reference: https://ctan.org/pkg/crossword

The CTAN catalogue lists the upstream work as “Free license not otherwise
listed”; it does not identify a standard licence. This starter contains newly
written clues and no upstream package files, artwork, or answer data.
