# Songs lyric and chord book

This starter uses the CTAN `songs` package to create a lyric-and-chord book
from a separate song-data file.  It demonstrates song metadata, chord syntax,
verses, a chorus, a capo marker, and an original public-domain-safe example
song.

Use `\[G]` immediately before a syllable to place a chord, and `^` at the
start of a later verse line to continue the verse without resetting its
layout.  The package also supports lyric-only books, slides, handouts,
transposition, tablature, and generated indexes.

Source: <https://ctan.org/pkg/songs>
