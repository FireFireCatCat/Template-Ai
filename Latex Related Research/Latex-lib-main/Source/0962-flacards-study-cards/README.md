# Flacards study cards

A cut-and-print flashcard starter using the `flacards` class. It demonstrates
front/back card content, a configurable three-column grid, and front/back
cutting guides.

The class is supplied by TeX Live, so it is not bundled. The prompts and
answers are original starter content.

Build with PDFLaTeX:

    pdflatex main

Source: https://ctan.org/pkg/flacards
