\cvsection[0.8]{项目经历}

\cvheading{OpenCurVe Resume}{LaTeX \headerdivider 开源项目}
\cvtagline{一个基于 CurVe 的开源、高度可定制单页 LaTeX 简历模板。}
\cvitem{\textbf{模块化：}将教育背景、实习经历、项目经历与技能拆分为独立文件，正文内容和视觉样式分离。}
\cvitem{\textbf{可定制：}颜色、字体、页边距、章节标题与条目样式集中定义在 \texttt{open-curve.sty} 中。}
\cvitem{\textbf{可移植：}优先使用 Times New Roman 与微软雅黑，字体不可用时自动回退到 TeX Live 自带字体。}
