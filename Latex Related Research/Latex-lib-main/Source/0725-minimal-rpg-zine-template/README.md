# Minimal RPG zine starter

This print-oriented zine starter follows the upstream project's A4,
two-column, binding-aware workflow while keeping the example source small and
editable. Adjust the inner margin before imposing pages for booklet printing.

Upstream source: https://github.com/wintermute-cell/osr-zine-template

Upstream licence: MIT. The upstream class uses the Coelacanth font package;
this starter uses standard TeX Live fonts and does not bundle upstream code.
