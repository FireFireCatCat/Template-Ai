# Questionnaire

An editable paper questionnaire starter with numbered questions, checkbox
options, instructions, and ruled response space. Replace the fictional field
study copy with your own survey instrument and add an ethics notice where
needed.

Research lead: <https://www.overleaf.com/latex/examples/questionnaire/xnyxksbbkrzv>.
The reviewed source did not state a redistributable upstream licence; the
catalogue warning records that uncertainty. No upstream content or branding is
bundled.
