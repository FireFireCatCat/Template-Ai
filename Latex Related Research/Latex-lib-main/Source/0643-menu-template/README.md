# Menu Template

A printable restaurant menu with a framed masthead, section rules, priced
dishes, descriptions, and an accessibility note. Replace the fictional venue
and dishes in `main.tex` with your own menu.

Upstream source: https://www.overleaf.com/latex/templates/menu-template/zvvtbqkzzbyp
