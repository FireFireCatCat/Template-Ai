# Economics Journal Article Bundle

An original economics working-paper starter inspired by the legacy collection
of journal styles in the CTAN `economic` bundle. It is intentionally portable:
the archive contains no upstream journal style files, publisher branding, or
logos, and uses standard LaTeX packages.

Source: https://ctan.org/tex-archive/biblio/bibtex/contrib/economic

The upstream bundle has mixed or unclear component licensing; that provenance
warning remains attached to this catalogue entry. Compile with PDFLaTeX.
