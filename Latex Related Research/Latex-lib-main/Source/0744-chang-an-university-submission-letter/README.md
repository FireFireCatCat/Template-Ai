# Chang'an University Submission Letter

An original neutral manuscript-submission letter starter based on the Overleaf
template for Chang'an University:
<https://www.overleaf.com/latex/templates/cover-letter-template-for-changan-university/czsxcvzncsbw>.

omitted; the archive contains fictional content and no upstream files. Compile
with PDFLaTeX.
