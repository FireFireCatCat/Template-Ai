# unitn-bimrep

A bimonthly doctoral-report starter using the installed `unitn-bimrep` class.
It demonstrates the required research, school/seminar attendance, and
production environments with editable examples.

The Unitn class is distributed under the MIT licence and is supplied by TeX
Live; its distribution-provided image is not bundled in this archive. The
class inserts the University of Trento report masthead when compiled with an
installation that provides that image. Source and licence:
https://ctan.org/pkg/unitn-bimrep

Compile with pdfLaTeX. Keep the three required environments in this order.
