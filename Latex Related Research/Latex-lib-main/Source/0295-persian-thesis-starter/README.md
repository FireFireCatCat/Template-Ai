# Persian Thesis Starter

This neutral starter is informed by [zarrabi/thesis-template](https://github.com/zarrabi/thesis-template),
listed as CC-BY-4.0 in the research ledger. Attribution is generated into the
download archive. The starter uses TeX Live's DejaVu fallback and does not bundle
the upstream project's fonts, institutional marks, or sample assets.

Compile `main.tex` with XeLaTeX. Replace the font and formatting choices with
those required by the relevant university before submission.
