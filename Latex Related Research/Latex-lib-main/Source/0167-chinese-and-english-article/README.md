# Chinese and English article

This self-contained bilingual starter follows the Chinese/English article
gallery example: title matter, a bilingual abstract and keywords, parallel
English and Chinese sections, equations, a table, and references. The original
gallery project uses its custom `chenart` package; that published project was
not independently downloadable during packaging, so this starter uses the
TeX Live `ctexart` class and standard packages rather than claiming to bundle
`chenart`.

The gallery identifies the source as LPPL 1.3c by Jack Chen. Retain attribution
when adapting the structure, and verify the current source licence and any
font requirements before redistributing a modified version.

Compile with XeLaTeX.
