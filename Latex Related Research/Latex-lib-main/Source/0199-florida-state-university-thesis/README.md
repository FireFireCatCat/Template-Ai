# Florida State University Thesis

Neutral dissertation starter based on the official [FSULaTeX template
lead](https://myweb.fsu.edu/bwhissel/fsulatex/download.html). It provides the
traditional title page, abstract, approval/declaration pages, contents, and
chapter structure while omitting university marks and upstream assets.

The institutional source does not state a licence. That is retained as a
warning for due diligence; no explicit redistribution or commercial-use ban was
found. Compile with `pdflatex main.tex`.
