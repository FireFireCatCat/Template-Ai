# Principia book starter

This starter turns the `principia` package into a small book-shaped working
document for formal-logic notes. It demonstrates Peanese connectives, scope
dots, proposition numbering, definitions, and substitutions while leaving the
chapter prose editable.

The upstream package is [LogicalAtomist/principia](https://github.com/LogicalAtomist/principia),
released under LPPL 1.3c by Landon D. C. Elkind. The required `principia.sty`
is included because it is not installed in the catalogue's pinned TeX image.
No upstream prose, images, or logo are included.

Compile with **pdfLaTeX**. Edit `main.tex`, then add chapters or replace the
sample argument with your own formal development.
