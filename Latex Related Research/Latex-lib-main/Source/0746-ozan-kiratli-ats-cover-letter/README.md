# Ozan Kiratli ATS Cover Letter

This is a clean, text-first application-letter starter based on the matched
ATS resume and cover-letter classes in Ozan Kiratli's repository. It keeps the
letter readable by people and text extraction tools: ordinary paragraphs,
selectable fonts, explicit contact details, and no decorative image layer.

Upstream reference: <https://github.com/ozankiratli/Resume-ATS-Friendly>

The upstream repository is marked LPPL-1.3c. This catalogue starter uses the
standard `article` class and does not bundle the upstream classes, fonts, or
personal data. Replace the synthetic identity, recipient, and date before
use.

Compile with PDFLaTeX.
