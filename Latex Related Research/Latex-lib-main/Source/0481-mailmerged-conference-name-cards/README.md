# Mailmerged Conference Name Cards

This starter follows the spreadsheet-driven workflow of the Overleaf
[Mailmerged Conference Name Cards](https://www.overleaf.com/latex/templates/mailmerged-conference-name-cards/mpwmfvkngdzq)
lead. The research record identifies CC BY 4.0 and requires attribution; the
archive supplies that credit automatically. Edit `participants.csv` (embedded
in `main.tex` for a self-contained download), then compile with XeLaTeX. The
sample identities and artwork are original and contain no upstream personal
data, logos, or photographs.
