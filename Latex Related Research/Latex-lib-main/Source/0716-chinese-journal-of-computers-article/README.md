# Chinese Journal of Computers article starter

An original Chinese/English-friendly computer-science article starter based on the public repository lead. It uses the TeX Live `ctex` package and contains no journal logo, upstream prose, bundled font, or publisher asset.

Source lead: <https://github.com/strive-yang/CHINESE-JOURNAL-OF-COMPUTERS--Latex-Template>

Compile with XeLaTeX. The repository's file-level licence and bundled-font provenance were not independently verified; these remain warnings.
