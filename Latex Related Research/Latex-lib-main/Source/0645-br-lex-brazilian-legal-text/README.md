# br-lex

A Brazilian legal-text article starter for drafting a concise normative
proposal. It uses the CTAN `br-lex` class and keeps the examples generic so
the document can be adapted without carrying real institutional data.

Upstream: <https://ctan.org/pkg/br-lex>

CTAN lists the package under LPPL-1.3c and identifies Youssef Cherem as its
author. The class is part of TeX Live, so it is not bundled here.

Compile with `pdflatex`.
