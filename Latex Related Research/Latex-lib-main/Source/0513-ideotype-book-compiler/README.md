# IdeoType book compiler

A directly compilable book-production starter based on the manuscript-to-book workflow described by [IdeoType](https://sourceforge.net/projects/ideotype/). It presents a production brief, structured-source example, transformation checklist, and build notes in a compact book layout.

SourceForge identifies IdeoType as MIT-licensed. This catalogue entry is an original LaTeX starter and does not bundle the upstream compiler, manuscript content, or assets. Use the upstream project when you need its XHTML-to-PDF conversion pipeline; use this starter when you need a straightforward editable LaTeX book source.
