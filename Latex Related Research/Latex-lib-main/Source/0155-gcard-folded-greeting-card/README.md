# gcard folded greeting card

This starter demonstrates George McBane's [`gcard`](https://ctan.org/pkg/gcard)
package. The package lays out `frontcover`, `insideleft`, `insideright`, and
`backcover` panels on one sheet, ready to fold into a card. Panels may be left
out when they are not needed.

`gcard` is part of TeX Live and is therefore not bundled here. Edit the four
panel environments in `main.tex`, then compile with PDFLaTeX. The example
uses fictional copy and deliberately contains no institutional marks.
