# Engineering and mathematics homework

This original starter follows the structure of the Overleaf
[Engineering/Mathematics Homework Assignment Template](https://www.overleaf.com/latex/templates/engineering-slash-mathematics-homework-assignment-template/qbqwkxskfwhp):
a cover page, course metadata, Given/Solution boxes, worked equations, and a
reflection prompt.  The sample values and prose here are new; no upstream
personal data, images, or source assets are included.

The Overleaf gallery record identifies the source as LPPL-1.3c.  This download
uses only standard TeX Live packages and the ordinary `article` class, so the
upstream class or any external asset does not need to be bundled.
