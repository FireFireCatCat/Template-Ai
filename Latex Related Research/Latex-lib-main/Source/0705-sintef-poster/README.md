# SINTEF poster

A portrait A0 scientific-poster starter based on Federico Zenith's
[`sintefposter`](https://www.overleaf.com/latex/templates/sintef-poster/hksprrptfntf)
workflow: strong header, `\block`/`\innerblock` hierarchy, two columns, and a
conclusion/footer area.

The catalogue document is self-contained on the pinned TeX Live image and
uses `tikzposter` rather than bundling the upstream `sintefposter` class. It
omits SINTEF logos and corporate font files; replace the fictional content and
footer before use. The upstream Overleaf page identifies the template as CC BY
4.0, so the packaged download carries attribution. SINTEF branding and marks
may have separate institutional terms.
