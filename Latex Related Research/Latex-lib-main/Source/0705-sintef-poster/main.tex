\column{0.47\paperwidth}
\begin{block}{Class description}
  The upstream `sintefposter` workflow reconfigures `tikzposter`: the
  \texttt{\\block} command gives the page its primary rhythm, the
  \texttt{\\innerblock} command creates a secondary level, and
  \texttt{\\column} controls the narrative width. This self-contained variant
  uses the same concepts with the TeX Live `tikzposter` class.
  \par\medskip\textbf{\color{sintefgreen}Requirements}\par
    Keep the title short enough for the A0 header. Use `pgfplots` for real
    plots, `graphicx` for figures, and replace this paragraph with the
    assumptions that govern your own result.
  \par\medskip\textbf{\color{sintefgreen}Caveat}\par
    A model can look accurate while hiding a distribution shift. Include a
    limitation block next to the headline result.
\end{block}

\begin{block}{Writing}
  Use the right column for the result and the decisions it enables. A reader
  should be able to understand what changed, how large the effect is, and
  what remains uncertain without opening the supplementary material.
\end{block}
