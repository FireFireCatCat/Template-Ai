# Newspaper newsletter starter

This three-column newsletter uses the CTAN `newspaper` package for the
masthead, issue metadata, headlines, byline, and article rules. The fictional
content demonstrates an observation story, a compact table, and a noticeboard
item; replace it with your own issue.

Upstream source: https://ctan.org/pkg/newspaper

Upstream licence: LPPL-1.3. The package is supplied by TeX Live and is not
bundled in this download.
