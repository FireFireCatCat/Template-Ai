# Meowmeow Cheatsheet

A compact bilingual revision-sheet starter based on
`ShevonKuan/meowmeowsheet`. It demonstrates short definitions, equations,
checklists, and a two-column layout that can be adapted to any subject.

The source is an original example and bundles no upstream fonts, artwork, or
class files.

Upstream reference: https://github.com/ShevonKuan/meowmeowsheet
