\sectiontitle{核心概念 / Core ideas}
\textbf{不变量 Invariant:} 在允许的操作下保持不变的量。\\
\textbf{复杂度 Complexity:} 记录输入规模 $n$ 增大时资源如何增长。\\
\textbf{抽象 Abstraction:} 保留接口，隐藏实现细节。

\sectiontitle{常用公式 / Useful formulas}
\[
 \sum_{k=1}^{n}k=\frac{n(n+1)}2,\qquad
 \sum_{k=0}^{\infty}r^k=\frac1{1-r}\quad(|r|<1).
\]
For a recurrence $T(n)=aT(n/b)+f(n)$, compare $f(n)$ with
$n^{\log_b a}$ before choosing a bound.

\sectiontitle{算法检查 / Algorithm checklist}
\begin{enumerate}
\item 明确输入、输出和边界条件 / define inputs, outputs, and boundaries.
\item 先写不变量，再选择数据结构 / state the invariant first.
\item 用小例子和极端例子测试 / test small and extreme cases.
\item 分析时间、空间和失败模式 / analyse time, space, and failure modes.
\end{enumerate}
