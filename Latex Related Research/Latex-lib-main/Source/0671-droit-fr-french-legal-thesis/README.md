# droit-fr legal thesis

This is an original French legal-thesis starter for the `droit-fr` class.  It
uses the class's French title-page metadata, hierarchy (`\partie`, `\titre`,
`\chapitre`, `\verset`), table of contents, footnote handling, and
BibLaTeX/Biber style.  The legal discussion and references are fictional
starter material and do not reproduce the upstream example.

The `droit-fr` bundle is distributed by CTAN under LPPL 1.3 or later and is
provided by TeX Live; this download therefore contains only the starter and
its bibliography, not the installed class or its documentation.  See the
[official CTAN package page](https://ctan.org/pkg/droit-fr) for the upstream
source and licence.  The upstream `droit-fr` bibliography style is from 2016
and does not compile with the pinned BibLaTeX release, so this starter selects
the maintained numeric style and records that substitution in `main.tex`.
