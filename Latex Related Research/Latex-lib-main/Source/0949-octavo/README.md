# octavo

A modification of the standard `book` class implementing
Tschichold/Rosarivo classical page-proportion and margin theory, plus
nine classical paper formats (foolscap, crown, post, largepost, demy,
medium, royal, superroyal, imperial) and signature imposition for hand
bookbinding.

## Class

Not bundled — ships with TeX Live. Class documentation: `texdoc
octavo`.
