\chapter{Introduction}
\label{ch:introduction}

\section{Motivation}

Large-scale distributed systems increasingly rely on approximate
consensus protocols to balance latency and consistency
\citep{lamport1998part}. This work studies how such protocols degrade
under network partition.

\section{Contributions}

The main contributions are:

\begin{enumerate}
  \item A formal model of partial-partition tolerance.
  \item An empirical evaluation summarised in \autoref{tab:results}.
  \item A reference implementation used to produce
    \autoref{fig:latency}.
\end{enumerate}

\section{Related Work}

Classical consensus protocols such as Paxos \citep{lamport1998part} and
Raft \citep{ongaro2014search} assume a fully connected network. This
thesis relaxes that assumption.
