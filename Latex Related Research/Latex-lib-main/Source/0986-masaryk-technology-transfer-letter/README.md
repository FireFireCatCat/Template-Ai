# Masaryk University Technology Transfer Letter

This starter represents the Overleaf gallery template [A Letter Template for
the Technology Transfer Office at the Masaryk University in Brno](https://www.overleaf.com/latex/templates/a-letter-template-for-the-technology-transfer-office-at-the-masaryk-university-in-brno/ypnkjtjymnzv).
It uses the bundled `muletter` class and demonstrates references, contact
metadata, enclosures, and carbon copies with original placeholder content.

The gallery entry is CC BY 4.0 by Vít Novotný. Attribution is included in the
download archive. Institutional branding is disabled in this portable starter;
use official marks only with permission. Compile with PDFLaTeX.
