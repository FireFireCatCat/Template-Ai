# Canada Study Permit Cover Letter

An original, self-contained study-permit letter starter inspired by the
modular application packet at
<https://github.com/deepmancer/canada-visa>. It contains fictional placeholders
and no government marks, personal data, or upstream files. The upstream
repository is Apache-2.0 licensed; verify current immigration requirements and
replace every bracketed field before use. Compile with PDFLaTeX.
