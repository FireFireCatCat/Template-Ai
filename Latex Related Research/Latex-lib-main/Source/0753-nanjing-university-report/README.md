# Nanjing University Report

An editable Chinese/English coursework-report starter based on
`Sensente/NJU_LaTex_Template`.

This catalogue starter is deliberately neutral: it does not bundle Nanjing
University logos, fonts, upstream source files, or official institutional
wording. Replace the sample sections and add approved artwork only when you
have the rights to distribute it.

Upstream reference: https://github.com/Sensente/NJU_LaTex_Template
