# Arbeitsblattgenerator worksheet

This original German-inspired worksheet starter is a static LaTeX companion
to the [Arbeitsblattgenerator](https://github.com/jochen-rath/Arbeitsblattgenerator)
project, a GPL-3.0 Python/LaTeX generator for exercise sheets and solutions.
It does not redistribute the upstream generator, Python modules, generated
examples, or IDE files.  Instead it provides an editable student/teacher sheet
with task, hint, worked-solution, and graph components using standard TeX Live
packages.  Change the fictional numbers and toggle the solution boxes as your
course requires.
