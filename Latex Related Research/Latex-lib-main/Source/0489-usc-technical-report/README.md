# USC Technical Report

This starter packages the legacy CTAN `techreport.sty` and demonstrates its
report metadata commands (`\reportnumber`, `\address`, and `\acknowledgment`)
with a standalone modern `report` document. The style was originally intended
as an option for the USC thesis class, so projects needing its original title
page and chapter hooks should pair it with the corresponding USCthesis setup.

CTAN identifies the style as unavailable in standard TeX Live. Its licence
status is not stated clearly in the package metadata; treat that as an explicit
licence/provenance warning and verify permission before redistribution.
