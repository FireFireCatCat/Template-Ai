# basic-template

The plainest possible starting point in this catalogue: one `article`
class, a title page, and section structure — nothing else.

## Files

- `main.tex` — the document. Start here.

## Building

    pdflatex main
    pdflatex main

Two passes resolve the table of contents / references if you add any;
the starter itself has none, so one pass is technically enough.
