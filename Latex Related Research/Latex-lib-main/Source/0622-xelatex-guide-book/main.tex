\chapter{Choosing Fonts with fontspec}

\section{Main, Sans and Mono Families}

XeLaTeX and LuaLaTeX both load system fonts directly through
\texttt{fontspec}, rather than requiring a font to be installed as TeX
metrics first \citep{knuth1984texbook}. Table~\ref{tab:families} lists the
three families a document typically sets.

\begin{table}[h]
  \centering
  \begin{tabular}{ll}
    \toprule
    Command & Sets \\
    \midrule
    \verb|\setmainfont|  & body text \\
    \verb|\setsansfont|  & sans-serif emphasis \\
    \verb|\setmonofont|  & code and verbatim text \\
    \bottomrule
  \end{tabular}
  \caption{The three font families \texttt{fontspec} configures.}
  \label{tab:families}
\end{table}

\section{A Note on Missing Fonts}

If a font a document asks for is not installed, \texttt{fontspec} raises an
error rather than silently substituting one. This starter uses DejaVu Serif,
DejaVu Sans and DejaVu Sans Mono, all installed here by default.
