# beamer-rl

A LuaLaTeX starter for right-to-left Beamer presentations. The example keeps
the content in a simple bilingual-safe structure and demonstrates how to load
the patched class with a regular Beamer theme. Add `\babelprovide` and your
RTL language in the preamble when adapting it to Arabic, Hebrew, Persian, or
another supported language.

Upstream: https://ctan.org/pkg/beamer-rl
Upstream licence: LPPL-1.3c-or-later.

The upstream package requires LuaLaTeX. The bundled class and helper package
are included for a self-contained starter.
