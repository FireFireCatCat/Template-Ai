# E-ink planner

An original, high-contrast monochrome planner starter for tablets and e-ink
devices. It includes a 2026 annual overview, a quarterly focus board, and a
daily-notes page. The layout intentionally uses no colour-dependent information,
images, external fonts, or shell-escape features.

The candidate source is [Eink-Calendar](https://github.com/alefaraci/Eink-Calendar),
which is released under Apache License 2.0. This catalogue starter is an
independent LaTeX implementation and does not bundle upstream code, fonts, or
artwork.
