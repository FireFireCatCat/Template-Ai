# Invoice Template

A small letter-based invoice starter following the compact workflow documented
by the original Overleaf example: sender address, customer letter, project
fees, and a closing note. It is easy to adapt for a freelancer or small
service business.

Compile with PDFLaTeX.

Upstream reference: https://www.overleaf.com/latex/templates/invoice-template/rpdlzpjmkfmj

The upstream work says the example may be distributed if its referral is kept.
That referral is preserved here. This catalogue starter is newly written and
does not bundle the upstream `invoice` package or copied blog content.
