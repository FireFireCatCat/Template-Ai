# Memo Template

This starter follows the field-based memo workflow documented by the Overleaf
[Memo Template](https://www.overleaf.com/latex/templates/memo-template/xfgfwnxzcgkf),
which uses the TexMemo package created by Rob Oakes and is marked LPPL 1.3c.
The catalogue version is a portable, freshly authored implementation of the
same useful ideas (`To`, `From`, `Date`, and `Subject` fields), with no
Overleaf logo or other gallery artwork.

Edit the four `\\memofield` lines and the memo sections in `main.tex`. Compile
with PDFLaTeX.
