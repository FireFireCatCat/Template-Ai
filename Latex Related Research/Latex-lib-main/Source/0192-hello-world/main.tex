\section{A little structure}
Sections, emphasis (\emph{like this}), and lists are all you need to begin:
\begin{itemize}
  \item Add a section with \verb|\section{...}|.
  \item Cite a source with \verb|\cite{...}| once you add a bibliography.
  \item Link to a page with \href{https://latextemplates.com}{a hyperlink}.
\end{itemize}
