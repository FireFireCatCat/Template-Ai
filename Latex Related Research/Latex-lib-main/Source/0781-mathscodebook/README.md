# mathscodebook

A mathematics-and-code book starter inspired by Yuri ODev's MathsCodeBook.
It demonstrates theorem statements, exercises, worked examples, code listings,
and a chapter-based textbook flow using standard TeX Live packages. The
upstream CC0 work is not bundled; all sample prose and code here are original.

The upstream project is dedicated to the public domain under CC0 1.0. Check
the licence of any code or figures you add to the starter separately.
