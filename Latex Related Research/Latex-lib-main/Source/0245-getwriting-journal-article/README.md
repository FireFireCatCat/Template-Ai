# getwriting journal article

This starter uses the `getwriting` class for a readable, double-spaced
format-free article.  It demonstrates the class's author/affiliation block,
line numbering, long-form sections, a table, an equation, a code block, and a
plain BibTeX bibliography.  The sample content and all layout examples are
original to this catalogue; no upstream photographs or personal data are
included.

The class is redistributed under the Unlicense.  The bundled Atkinson
Hyperlegible TrueType files are separate font assets; their OFL-1.1 terms are
included in `fonts/OFL-1.1.txt`.  The class and font files came from the
[upstream project](https://github.com/muktapalshikar/getwriting), whose
README identifies the font source and intended use.
