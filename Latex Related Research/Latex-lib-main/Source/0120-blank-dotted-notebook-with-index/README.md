# Blank dotted notebook with index

An original printable dotted notebook starter inspired by the Overleaf
`notebook-blank-240pages` template. It provides an index page, numbered
sections, a project key, and repeatable dotted writing pages for experiments,
field notes, or planning.

Compile with PDFLaTeX. The upstream page and its licence status should be
checked before redistributing adaptations; this catalogue entry records that
status as an unresolved warning and does not copy upstream source or assets.

Source: https://www.overleaf.com/latex/templates/notebook-blank-240pages/hxgyxgtvfytx
