# Awesome Beamer

An original, self-contained presentation starter inspired by the
`awesome-beamer` project by Lukas Pietzschmann. It keeps the upstream idea of
an opinionated, typography-first talk with a strong title page, section
transitions, and a progress-aware footer, while using only standard Beamer and
TikZ primitives.

Upstream source: https://github.com/LukasPietzschmann/awesome-beamer
