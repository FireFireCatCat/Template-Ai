# unigrazpub

A German-language monograph starter for the University of Graz Library
Publishing Services class. It demonstrates title matter, contents, chapters,
an example table, and an imprint using original sample text.

The CTAN package is released under LPPL 1.3c or later and requires LuaLaTeX in
its documented workflow. The class is supplied by TeX Live and is not bundled;
replace the sample text and add your own bibliography and publication metadata.
