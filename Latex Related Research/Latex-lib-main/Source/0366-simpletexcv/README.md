# simpletexcv — restrained CV and cover letter

A deliberately plain CV and matching cover letter from
`github:lorenzosaino/simpletexcv` (MIT) — no icons, no colour beyond
optional link colouring, built on the plain LaTeX `letter` class. Good
starting point if AltaCV/Awesome-CV-style graphical CVs are too busy for
your field.

## Files

- `main.tex` — the CV. Start here.
- `cover_letter.tex` — a matching cover letter, same author details.
  Compiles to its own, separate PDF.
