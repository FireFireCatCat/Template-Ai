# SPIE Optical Engineering

This starter demonstrates the SPIE `opteng` package in its Optical Engineering journal mode. It includes the title, author and affiliation block, subject terms, manuscript metadata, a compact two-column article, equation, table, figure, and references.

The `opteng` package is supplied by the pinned TeX Live image and is not copied into this starter. Its CTAN package archive does not contain an explicit redistribution grant beyond the CTAN licence label, so this entry is promoted with an unknown-licence warning under the catalogue policy. Check SPIE's current author instructions before submission. The copyright and DOI values in this example are placeholders.

Compile with PDFLaTeX.
