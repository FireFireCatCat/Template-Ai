# booktemplate

A quiet 6.25 × 9.25 inch book starter inspired by [Nithiya Streethran's booktemplate](https://gitlab.com/nithiya/booktemplate). It demonstrates a preface, drop-cap opening, table of contents, chapters, an appendix, and a colophon.

The upstream project is released under LPPL-1.3c. This starter is original and does not bundle the upstream artwork or EB Garamond font asset; replace the sample text and adjust the preamble for your own edition.
