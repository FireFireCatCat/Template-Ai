\section{Introduction}

\begin{frame}{Why Metropolis}
  Metropolis is a clean, high-contrast Beamer theme built around three ideas:
  \begin{itemize}
    \item Minimal visual noise, maximum room for content
    \item A single accent colour used consistently for structure
    \item An optional progress bar so the audience always knows where they are
  \end{itemize}
\end{frame}
