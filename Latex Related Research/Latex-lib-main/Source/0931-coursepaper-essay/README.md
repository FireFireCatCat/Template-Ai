# Coursepaper Essay

This starter uses the CTAN `coursepaper` class for a final, double-spaced
course paper.  It demonstrates the class-specific course metadata commands,
abstract, table, equations, and bibliography with original content about
queueing-system design.

The installed `coursepaper.cls` is used from the pinned TeX Live image and is
not bundled in the archive.  CTAN describes the package as “other-free” but
does not provide a standard SPDX identifier; that provenance/licence
uncertainty is retained as a warning under the catalogue's promotion policy.

Compile with PDFLaTeX.  Replace the metadata and the sample sections with your
own paper.
