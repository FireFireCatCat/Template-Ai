# MUL poster

A large-format scientific-poster starter based on the Montanuniversität Leoben
(`MUL_poster`) gallery design identified in the research queue. It uses a
high-contrast black/orange header, three readable content columns, a result
callout, and a limitations/next-step rail.

The Overleaf gallery entry identifies the institutional style but the reviewed
page did not provide a file-level redistribution grant. This starter is thus
promoted with a provenance/licence warning under the catalogue policy. It is
self-contained, does not bundle the MUL class, logos, style-guide artwork, or
institutional fonts, and is not an official MUL publication.
