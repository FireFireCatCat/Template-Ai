# Bilkent Economics Beamer theme

This starter demonstrates the `beamertheme-bilkent-econ` package with an
original three-slide deck, a result diagram, a table, co-author metadata, and
the theme's title/footer treatment. It uses DejaVu Sans because Arial is not
part of the pinned TeX image.

Upstream source: https://ctan.org/pkg/beamertheme-bilkent-econ

Upstream licences: LPPL-1.3c for the theme code; the package identifies its
institutional identity assets separately. The theme and logo are supplied by
TeX Live and are not bundled here. Bilkent names and marks are not an
endorsement of this starter.
