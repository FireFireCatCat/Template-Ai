# Elsevier book

An editable Elsevier book-project starter using the upstream `elsevierbook`
class family. Choose the layout model in `main.tex`, then replace the included
title page, front matter, chapters, appendices, and references with your own
files. The class files are under `sty/` as in the upstream project.

This package is publisher-specific. Check the current Elsevier author
instructions and the bundled LPPL terms before submission.
