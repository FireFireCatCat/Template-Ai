# Royal Society of Chemistry article

This self-contained starter follows the structure of the Royal Society of
Chemistry's official LaTeX article and communication templates: title matter,
abstract, chemistry-oriented sections, equations, tables, figure guidance,
and a numbered reference list.

The RSC publisher page provides template downloads but does not grant a
reusable licence for those files. This catalogue entry therefore uses an
original standard-LaTeX starter, does not bundle RSC class files, logos, or
publisher artwork, and records the upstream licence as unknown. Check the
current journal-specific author instructions before submission.

Source: https://www.rsc.org/publishing/publish-with-us/publish-a-journal-article/article-templates

Compile with PDFLaTeX.
