# Austrian Journal of Statistics article starter

This self-contained starter follows the AJS manuscript structure: title and
author metadata, abstract and keywords, numbered sections, an equation, a
table, an address block, and a bibliography. It leaves out the publisher
logo and uses neutral example data.

The Overleaf template is marked Creative Commons Attribution 4.0. The AJS
site describes the journal's articles as CC BY, but authors should confirm
the current journal and template terms before submitting.

Source: https://www.overleaf.com/latex/templates/austrian-journal-of-statistics-template/qskpxhjnqkbj
