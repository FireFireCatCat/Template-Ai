# Frostybee modular homework

A modular computer-science assignment starter based on the documented feature
set of Frostybee's `latex-homework`: a cover block, revision history, grading
scheme, notes, and structured problems.

Upstream: <https://github.com/frostybee/latex-homework>

The upstream repository identifies itself as MIT-licensed. This catalogue
starter is an original, self-contained `article` document and does not bundle
upstream source, fonts, icons, or images.

Compile with `pdflatex`.
