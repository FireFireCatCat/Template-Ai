# Tsinghua Letterhead

This starter represents [A Simple Tsinghua Letterhead Template](https://www.overleaf.com/latex/templates/a-simple-tsinghua-letterhead-template/zhpywsjswnjs),
published in the Overleaf gallery as CC BY 4.0 by 文豪. It preserves the
XeLaTeX letterhead structure, Chinese content, date helper, header, footer,
and signature layout while replacing personal details with placeholders.

The upstream logo is intentionally omitted: this portable version uses a
text-only university header, so it does not imply permission to redistribute
institutional artwork. Attribution is included in the archive. Compile with
XeLaTeX.
