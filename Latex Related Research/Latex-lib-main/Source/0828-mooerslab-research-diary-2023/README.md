# Research diary 2023

This is an original modular annual-diary starter with month chapters, dated
experiment entries, a raw-measurement table, comparison decisions, and an
appendix for an annual plan. Extend it by adding sections or moving each month
into its own source file.

It follows the documented laboratory/log-book use case of MooersLab's 2023
diary. No upstream source, prose, figures, or fonts are bundled. The upstream
repository includes a GPL-3.0 license notice: <https://github.com/MooersLab/diary2023inLaTeX>.
