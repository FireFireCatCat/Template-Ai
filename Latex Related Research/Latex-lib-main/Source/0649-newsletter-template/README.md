# Newsletter Template

This starter is an original three-column newsletter layout inspired by the
`latex-newsletter-template` project by Sathyam Vellal. It uses standard LaTeX
packages and keeps the editorial pieces modular: masthead, dateline, pull
quote, dispatch box, short sections, and a compact calendar.

Upstream source: https://github.com/sathyamvellal/latex-newsletter-template
