# photobook

A visual book starter using the CTAN `photobook` document class. It
demonstrates page-sized cells, inline cells, colour panels, captions, a table
of contents, and a production colophon without bundling upstream images.

`photobook` is distributed under the 3-clause BSD licence and is supplied by
TeX Live. Replace the drawn panels with your own photographs using the
documented `\\imagecell` macro; check the licence and attribution requirements
of every image you add.
