<h1>La règle des mots

Une balise s'écrit <<...>> et ses attributs se lisent d'un coup d'œil :
un <cle>{mot français en minuscules} est un style, un alignement ou un saut (gras, centre, 2tabulations) ; une <cle>{couleur} se nomme en français, composés compris (bleu marine, vert forêt) ; une
<cle>{taille} s'écrit Npt.

<h1>Échappements

Une poignée de caractères pilote le langage ; pour les afficher, on les double — c'est toute la règle.

<Affiche>un cadre avec un fond bleu lavande, une bordure pourpre, des coins arrondis de 3 mm et un titre {Doubler rend littéral} {
	Chevrons littéraux : << et >>. Accolades : {{ et }}. Dièse : ##. Dollar : $$.

	Une paire équilibrée s'affiche comme une seule, donc l'ensemble en
	compréhension {{ x : x > 0 }} et l'ensemble vide {{}} s'écrivent
	par paires.

	Tiret bas x_1, esperluette a & b, 50% de remise, a ~ b et le chemin
	C:\Users\Léa\Documents s'écrivent tels quels.
}

Un retour à la ligne dans le paragraphe est la balise <<nouvelle ligne>> :

<Affiche>un cadre avec un fond bleu lavande, une bordure pourpre et des coins arrondis de 3 mm {
	Première ligne d'une adresse <nouvelle ligne> seconde ligne, même
	paragraphe.
}

<h1>Tableaux avancés

<h2>Fusions déduites de la forme

Aucune fusion ne se déclare. Une rangée plus courte que le tableau étend sa dernière cellule jusqu'au bord droit : le titre, seul sur sa rangée, couvre les quatre colonnes. Une entête suivie de plusieurs rangées de données descend sur autant de lignes : Lundi porte deux crochets, il couvre deux rangées.

<Dresse>un tableau [mc, mg, mc, mc] avec des bordures {
	Bulletin trimestriel
	Jour	Matière	Note	Coef.
	Lundi :	[Maths ; 15 ; 4]
				  [Français ; 12 ; 3]
	Mardi :	[EPS ; 16 ; 2]
	Moyenne :	[13,7]
}

<h2>Entêtes emboîtées

Les entêtes verticales se collent aux données : la dernière touche le crochet, celle d'avant la précède, et ainsi de suite. Les tabulations ne servent plus qu'à aligner la source à l'œil — le tableau a la forme qu'on lui voit.

<Dresse>un tableau [mc, mc, mg, md] avec des bordures {
	Semaine	Jour	Matière	Note
	S1 :	 Lundi :	[Maths ; 15]
								 [Français ; 12]
				Mardi :	[EPS ; 16]
	S2 :	Lundi :	[Maths ; 18]
}

<h2>Une image dans une cellule

Une cellule de tableau accueille une formule ou une image, pas seulement du texte — chaque colonne garde son placement propre.

<Dresse>un tableau [mc, hg, bd] avec des bordures {
	Animal	Formule	Valeur
	[<Insère une image avec une largeur de 18 mm, dans le dossier {IMAGES}>{chat.png} ; $1/2 + 1/3$ ; $5/6$]
	[<Insère une image avec une largeur de 18 mm, dans le dossier {IMAGES}>{chien.png} ; $racine(2)$ ; $1,41$]
}

<h2>Couleurs du tableau

fond colore le corps, la bordure prend sa couleur, l'entête les siennes — sans cadre autour. Les couleurs d'entête habillent toutes les cellules d'entête, la rangée du haut comme la colonne de gauche.

<Dresse>un tableau [mc, mg, mc] avec des bordures, un écart de 3 mm, un fond bleu Alice, une bordure bleu marine et un entête en blanc sur fond bleu marine {
	Jour	Matière	Note
	Lundi :	[Maths ; 15]
	Mardi :	[Français ; 12]
}

<h2>Rangées dynamiques

Le nombre de colonnes est vérifié à chaque rangée, donc boucles et interpolation vivent dans un tableau.

<Dresse>un tableau [mc, mg, mc] avec des bordures {
	Table des carrés
	n	Légende	Carré
	pour n de 1 à 3 {
		[#n ; ligne #n ; $#n^2$]
	}
}

<h1>Grilles : la maquette en zones nommées

La grille dispose des zones à la façon d'une maquette : le plan dessine la page avec un mot par case, un nom répété fusionne ses cases, un point marque une case vide. Chaque zone se place et s'habille en langage naturel — [nom : en haut, à gauche] ou le code court [nom hg].

<page suivante>

<Affiche>une grille avec des zones:["titre titre date", "consigne corps corps", "logo corps corps"] des bordures et un écart de 3 mm {
	[titre : en haut, à gauche, avec un fond bleu Alice et une bordure bleu marine]{
		<bleu marine gras 14pt>Contrôle de mathématiques
	}
	[date : en haut, à droite]{
		Le 12 mai
	}
	[consigne: au milieu, au centre, avec un fond gris perle]{
		Calculatrice autorisée.
	}
	[logo : au milieu, au centre]{
		<Insère une image avec une largeur de 20 mm, dans le dossier {IMAGES}>{oiseau.png}
	}
	[corps: en mc]{
		Résoudre $x^2 - 5x + 6 = 0$ et vérifier les deux solutions.
	}
}

<h1>Imbrication et titres longs

Un conteneur accueille tout ce qu'un autre accueille : les blocs s'emboîtent aussi profondément que la page le permet.

<Affiche>un cadre avec un fond blanc fumé,  une bordure gris anthracite, des coins arrondis de 2 mm et un titre {Emboîtement} {
	<au centre>{<gras>{Centré, gras, encadré : trois accolades fermantes à la suite, sans ambiguïté.}}
}

Un titre de cadre est du texte ordinaire : il peut courir sur deux lignes et porter un chevron qui n'a rien d'une balise :

<Affiche un cadre avec un fond rose brumeux, une bordure cramoisie, des coins arrondis de 3 mm et un  titre {seuil a> b, vérifié sur deux lignes}>{
	Le titre a débordé sur une seconde ligne et contenait un $>$ littéral.
}
