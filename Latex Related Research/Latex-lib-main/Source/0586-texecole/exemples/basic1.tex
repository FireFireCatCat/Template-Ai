	<h1>Paragraphes et caractères spéciaux
	
	Un document texecole s'écrit comme du texte ordinaire.
	Le tiret bas x_1, l'esperluette a & b, le pourcentage 50% et le tilde a ~ b s'écrivent tels quels, comme un chemin C:\Users\Léa\Documents.
	Les caractères qui pilotent le langage se doublent pour s'afficher : << chevrons >>, {{accolades}} et ##dièse.
	De même, il est nécessaire de doubler le caractère $$ pour qu'un dollar isolé s'affiche tel quel : il reçoit 5 $$ d'argent de poche de ses parents, puis encore 3 $$ de sa tante et enfin 6 $$ de ses grands-parents.
	Les zones mathématiques s'apparient ligne par ligne.

	}
	
	<h1>Fractions, puissances et indices
	
	Les fractions s'écrivent avec /, les puissances avec ^, les indices avec _. L'exposant se lie à l'atome voisin, jamais à la fraction entière — les parenthèses l'y hissent :
	
	<Affiche>un cadre avec un fond bleu Alice, une bordure bleu marine et des coins arrondis de 3 mm {
		$1/2$, $a/b/c$, $x^2 + y^2 = r^2$, $x_1 + x_2$
		
		$a^2/b$ — la puissance reste sur $a$
		
		$a/b^2$ — la puissance reste sur $b$
		
		$(a/b)^2$ — les parenthèses la hissent sur la fraction
	}

	<h1>Calculs et interpolation
	
	Un calcul s'écrit entre #{ et } — la frontière est exacte, une lettre collée à la valeur n'est jamais avalée :
	
	soit n = 7
	
	<Affiche>un cadre avec un fond vert menthe, une bordure bleu canard et des coins arrondis de 3 mm {
		$n = #n$, donc $n^2 = #{n*n}$ et $n/2 = #{n/2}$
		
		$#{n}x$ vaut sept fois $x$, et $#{n}x^2$ garde sa puissance.
		
		La moitié de deux façons : $1/2 = #{1/2}$, à côté du littéral $0,5$.
		
		Arrondis : #{arrondi(5/3; 2)}, défaut #{défaut(3,7)}, excès #{excès(3,2)}.
	}

	<h1>Listes
	
	Une liste s'écrit <<Dresse une liste STYLE>> — un élément par ligne, sans balise d'élément. Puces : à puces, à puces vides, à puces carrées, sans puce ;
	numérotées : numérotée, alphabétique, alphabétique majuscule, en chiffres romains, en chiffres romains majuscules ; à cocher pour les cases.
	
	<Dresse>une liste numérotée {
		Lire l'énoncé
		Souligner les mots importants
		Rédiger la réponse
	}
	
	<h1>Un tableau simple
	
	Une rangée de données s'écrit entre crochets, les cellules séparées par un point-virgule. Les colonnes se déclarent dans la balise, un code par colonne : la première lettre est verticale (h/m/b), la seconde horizontale (g/c/d) — et le langage naturel fait aussi bien : en haut, à gauche vaut hg.
	
	<Dresse>un tableau [mg, mc, md] {
		[Pomme ; Poire ; Prune]
		[Chat ; Chien ; Cheval]
	}
	
	Rien ici hors des crochets : le tableau n'a donc pas d'entête, ce n'est qu'un jeu de colonnes alignées.
	
	<page suivante>bordures trace les filets. Tout ce qui s'écrit hors des crochets est une entête : la rangée du haut le devient sans qu'on ait à le dire.
	
	<Dresse>un tableau [mc, mg, md] avec des bordures {
		Figure	Formule	Valeur
		[carré ; $1/2 + 1/3$ ; $5/6$]
		[cercle ; $racine(2)$ ; $1,41$]
	}

	<h1>Insérer une image
	
	Une image s'insère par <<Insère une image>> ; les dimensions se disent en prose, comme tout attribut — ici une largeur, ailleurs un côté ou une légende. Le dossier se précise <<dans le dossier {...}>> quand l'image ne vit pas à côté du fichier source.
	
	<Insère une image avec une largeur de 30 mm, dans le dossier {IMAGES}>{chat.png}
	
	Une légende s'ajoute avec <<et la légende {...}>>, sous l'image :
	
	<Insère une image avec une largeur de 30 mm et la légende {Cinq pommes}, dans le dossier {IMAGES}>{pommes.png}
	
	<h1>Une image dans un cadre
	
	Un cadre accueille une image comme n'importe quel autre contenu ;
	<<au centre>> la place au milieu de la largeur disponible.
	
	<Affiche>un cadre avec un fond bleu Alice, une bordure bleu marine et un titre {Combien de billes ?} {
		<au centre>{<Insère une image avec une largeur de 60 mm, dans le dossier {IMAGES}>{billes.png}}
		
		Compte les billes de la photo : il y en a #n.
	}
