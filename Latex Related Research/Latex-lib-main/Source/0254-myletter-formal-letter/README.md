# Myletter Formal Letter

This starter targets the CTAN `myletter` class, the compatibility alias for
Axel Kielhorn's configurable `akletter` class.  It demonstrates sender
identity, telephone and email fields, a subject, recipient address, opening,
closing, copy line, and enclosure.

The class is supplied by the pinned TeX Live image and is not bundled.  The
archive includes only the starter's own `myletter.cfg` letterhead override;
it does not copy or modify the distribution configuration.  CTAN identifies
the package as LPPL 1.0 or later.  Compile with PDFLaTeX.
