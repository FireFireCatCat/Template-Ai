# Amnestyreport

An original community-safety and human-rights report starter using the
`amnestyreport` class. Replace the fictional Northbridge material with your own
evidence and keep the method and evidence-register sections when adapting it.

The class is supplied by TeX Live, so it is not bundled here. The upstream CTAN
package is released under the LaTeX Project Public License 1.3:
<https://ctan.org/pkg/amnestyreport>.

The `freefonts,nologo` options intentionally avoid Amnesty International fonts
and logos; no third-party artwork is included.
