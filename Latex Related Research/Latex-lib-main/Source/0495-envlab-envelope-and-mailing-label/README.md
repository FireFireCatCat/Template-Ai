# EnvLab Envelope and Mailing Label

This starter represents the CTAN `envlab` package (version 1.2), which
extends the standard LaTeX letter class with printable envelopes and mailing
labels. It demonstrates automatic labels from a letter plus a manually
generated address label using `\startlabels` and `\mlabel`.

The package is distributed under the LaTeX Project Public License and is
provided by the pinned TeX Live image; it is not bundled. Compile with
PDFLaTeX. Printer-specific dimensions and postal barcode rules should be
checked before production mailing.
