# OER bookdown textbook

A compact open-textbook starter based on [CrumpLab/OER_bookdown](https://github.com/CrumpLab/OER_bookdown). It demonstrates a textbook front matter section, learning-oriented chapters, a table, publishing paths, and a revision/sharing chapter.

The upstream book is CC BY-SA 4.0 and explicitly permits commercial redistribution with attribution and the same licence for adaptations. This catalogue starter is original sample content and does not copy the upstream chapters, figures, or source files. The upstream project uses R/bookdown for multi-format output; this entry is the directly compilable LaTeX PDF starting point.
