# ABNT academic-journal article

This starter implements the author-facing structure shown by the IBICT
academic/scientific-journal model: multilingual metadata, author affiliations,
abstracts, ABNT-oriented section structure, quotations, tables, equations,
and a references section. It uses standard LaTeX packages so it can be read
and adapted without bundling the gallery's `abakos` package or institutional
artwork.

The Overleaf gallery lists the source as CC BY 4.0 by Lucas Rodrigues Costa.
The example's journal name, dates, identifiers, and logo are placeholders;
replace them and check the current ABNT and journal instructions before use.

Source: https://www.overleaf.com/latex/templates/modelo-latex-abnt-para-revistas-academicas-e-cientificas/gbtdpmrdwnrx

Compile with PDFLaTeX.
