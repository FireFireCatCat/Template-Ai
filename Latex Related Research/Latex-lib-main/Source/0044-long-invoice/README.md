# longinvoice

A XeLaTeX invoice starter designed for invoices whose line-item table may grow
across pages. It uses a restrained colour system, `longtable` headers, and a
separate payment summary so the document remains useful beyond a one-page
example.

Compile with XeLaTeX.

Upstream reference: https://gitlab.com/asabina/naw_tex
