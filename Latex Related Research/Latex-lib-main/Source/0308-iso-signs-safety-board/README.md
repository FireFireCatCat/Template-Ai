# ISO signs safety-board starter

This landscape notice demonstrates the CTAN `isosigns` package in a compact
three-column safety board. `\Isosign[scale=...]{page}` selects a pictogram
from the package's supplied sign sheet; replace the sample page numbers with
the symbols appropriate to your site.

Upstream source: https://ctan.org/pkg/isosigns
