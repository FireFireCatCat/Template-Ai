# Thalie drama-play starter

This starter uses the CTAN `thalie` package to typeset a play with a dramatis
personae, acts, scenes, character lines, and stage directions. Replace the
fictional characters and dialogue with your own production text.

Source: <https://ctan.org/pkg/thalie>
