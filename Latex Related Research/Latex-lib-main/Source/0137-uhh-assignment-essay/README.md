# UHH Assignment Essay

An essay-and-assignment starter using the University of Hamburg
`uhhassignment` class. It provides course, tutor, group, sheet-number and
student metadata, numbered tasks with subtasks, and a compact hand-in layout.

The example is original prose about evidence and counterfactuals. Replace the
metadata commands near the top of `main.tex`, then edit or add `\task` and
`\subtask` sections. The purple `\todo` marker from the class is available
while drafting.

`uhhassignment.cls` is supplied by TeX Live and is not bundled here.
The upstream class is LPPL-1.3c; source: https://ctan.org/pkg/uhhassignment

## Build

    pdflatex main
