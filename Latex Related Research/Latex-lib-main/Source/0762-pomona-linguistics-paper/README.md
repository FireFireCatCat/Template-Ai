# Pomona Linguistics Paper

A compact linguistics paper with reusable preamble conventions, numbered examples, and a quick-reference-style appendix.

This is an original, neutral starter based on the cited upstream lead. Upstream logos, sample prose, photographs, fonts, and other third-party assets are not bundled.
