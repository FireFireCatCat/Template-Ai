# Gijs Pennings homework

An approachable problem-set starter inspired by Gijs Pennings's `latex-homework`
class. It keeps the useful assignment rhythm—course header, numbered problems,
parts, solutions, and a bibliography—while keeping the starter self-contained
in one editable `main.tex` file.

Upstream: <https://github.com/gijs-pennings/latex-homework>

The upstream repository identifies the class as ISC-licensed. This catalogue
starter is an original document and uses only standard TeX Live packages; no
upstream class code or personal data is bundled.

Compile with `pdflatex`.
