This thesis is, in fact, a worked example of the IIT (BHU) thesis \LaTeX{}
class itself. Chapter~\ref{ch:getting-started} walks through the class's
core typesetting mechanisms -- sectioning, equations, footnotes,
nomenclature and citations -- using the history of the Lorem Ipsum
placeholder text as its running example. Chapter~\ref{ch:my-second-chapter}
demonstrates document structure in more depth: nested lists, hidden
sections, figures and subfigures, and landscape pages for wide content.
Chapter~\ref{ch:my-third-chapter} covers table formatting, following the
established typographic convention of using horizontal rules sparingly
and never vertical ones. Together, the three chapters give a new user
everything needed to start a real thesis from this template rather than
from a blank file.
