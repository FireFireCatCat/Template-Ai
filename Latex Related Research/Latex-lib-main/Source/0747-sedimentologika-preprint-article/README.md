# Sedimentologika preprint article

This is an original, fictional sedimentology article starter for the
`sedimentologika` class.  It demonstrates the class's plain-language summary,
structured author metadata, CRediT roles, declarations, table, and
BibLaTeX/Biber bibliography.  It does not include the upstream journal's
photographs, prebuilt PDFs, translation fonts, or branding assets.

The class is redistributed under LPPL-1.3c.  Its class-level notice and the
REUSE-declared font licence notices are retained in `LICENSES/`.  The class
requires four Noto assets by filename, so those OFL-1.1 font files are
included; upstream photographs, prebuilt PDFs, translation fonts, and journal
branding remain omitted.  See the [upstream repository](https://github.com/Sedimentologika/LaTeX_templates)
for the full journal template and asset manifest.  Compile with LuaLaTeX.
