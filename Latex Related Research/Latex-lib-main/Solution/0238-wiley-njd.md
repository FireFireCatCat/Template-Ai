## Verdict
The zip is Wiley's own author kit (authors.wiley.com; USG.cls says "copyright by Wiley ... for Wiley Journals", USG.cls:4-11, and the public guidelines PDF ships beside it), so by the rubric's official-kit ruling `class.USG` is a published way: its behaviour is chosen by options (USG.cls:75-105), it is generic ("a generic template designed for use by multiple journals", Optimal-Design-layout.tex:113-114) and an emitter prints it as `\documentclass[ASNA,twocolumn]{USG}` plus class commands. The sample defines no macro of its own (grep: no `\newcommand`, `\def`, `\newenvironment`) and adds only `anyfontsize`, `colortbl`, `xcolor`, `steinmetz`; every body construct is class vocabulary or a published package, so the look is carried by the class (evidence about the class dimension, not the component ways). USG.cls is itself heavy hand-written code (own `\@startsection`, `\@makecaption`, a `\@maketitle` with a tikzpagenodes logo overlay, hand-rolled author counters); that code sits inside the published way and does not block, but it is listed in "Bespoke code" with scope tags so the result can be re-read if the class were treated as zip-local (it would then be BESPOKE/class and ART/class, i.e. `no`). Assets: logos and badges ship as `.eps` plus pre-converted `*-eps-converted-to.pdf` in `images/` (pdfTeX converts EPS through epstopdf when the converted file is not used; treated as asset preparation, not EXTERNAL), and only two `.bst` files ship (`wileyNJD-Chicago*.bst`) although other class options name absent `WileyNJD-*.bst` files (USG.cls:1929, 1937, 1946, 1964, 1978, 1986, 1993, 2001).
