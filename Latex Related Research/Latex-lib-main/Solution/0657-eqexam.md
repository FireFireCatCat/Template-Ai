## Verdict
The exam look is carried by a published package, so the examples under `examples/` reduce to `class.article` + `exam.questions` (the package eqexam is the parameter) + kernel and amsmath commands; taken alone they would be yes. The answer is no because the manifest's main sample, the manual, cannot be shown recoverable: it loads a style `eqexaman` that is not in the zip and whose source I could not read, and it carries an Acrobat JavaScript `docassembly` block. Other samples add runtime-only server pieces (survey submission) that are noted but not counted. A wrong yes costs more, so with an unreadable dependency in the main sample the rubric's tie-break gives no.

## Blockers
- `BESPOKE/preamble` `\usepackage{eqexaman}`: a manual-support style that is neither shipped in the zip nor named on the CTAN pages read (eqexam, acrotex); the manual's body markup `\cs`, `\newtopic`, `\redpoint`, `\CMD`, `\cAcroEB`, `\dCmd` environment is not defined in the manual preamble, so it presumably comes from `eqexaman` or `aeb_pro`; no reduction can be written (doc/eqexamman.tex:26; used e.g. doc/eqexamman.tex:268, 2964, 5243)
- `EXTERNAL/preamble` `docassembly` environment of AeB Pro/insdljs: Acrobat JavaScript (`\appopenDoc`, `\docSaveAs`, `\addWatermarkFromFile`, `\executeSave`) that opens a background PDF from `C:/Users/Public/Documents/ManualBGs/` (outside the zip) and saves a watermarked copy; it reads as work for Acrobat Pro on the finished PDF, not for TeX (doc/eqexamman.tex:184-218; AeB Pro documentation not read)

## Lib changes
- New ways proposed: `math.everymath` `\everymath` and `\everydisplay` (TeX primitives, as the lib already admits raw parameters in `sp.lengths` and `sp.penalties`), pdfLaTeX. W1: TeX primitive parameters of the kernel format. W2: in the samples the value is one of the closed list of style switches `\displaystyle` `\textstyle` `\scriptstyle` `\scriptscriptstyle`; a body with other code would be bespoke, as leaders are in `sp.rule`. W3: serves any document that wants inline maths in display style. W4: one preamble line. Not `math.kernel` (display environments and numbering) and not `math.eqnumber` (`leqno`, `fleqn`).
- Considered, not proposed: `srcltx` (editor source specials, no printed effect, like the rejected `sys.compat-load`; doc/eqexamman.tex:28), `calc`, `ifpdf`, `ifxetex`, `xkeyval` (load-only helpers inside eqexam, eqexam.dtx:135-140, 1040).
- Existing ways used for the first time by the lib: none needed (the consolidator computes this)
