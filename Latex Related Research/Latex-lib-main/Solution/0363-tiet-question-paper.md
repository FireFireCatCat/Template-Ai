## Verdict
The look is carried by one published class, `class.tiet-question-paper` (CTAN, in TeX Live), which loads article and sets geometry, enumitem list labels, the title block and a rule command; the sample adds only string variables, `\maketitle`, nested `enumerate` and `align*` math. Everything the sample uses maps to lib ways, the sample defines no macro of its own, and there is no artwork and no external tool. This is a class-carried yes: it is evidence about the class dimension, not about the component ways. It rests on W1 (the class is published); the one construct that would be irreducible if the class were zip-local is `\onedot` (cls:315-316), which the sample never calls (see Bespoke code).

## Class setting
- Class: `class.tiet-question-paper` options: `11pt,a4paper,onecolumn` (tiet-question-paper-sample.tex:1). Unknown options are forwarded to article (cls:20); the class then loads `article` with `11pt,a4paper,onecolumn` (cls:22), so the parent is `class.article`.
- Class-native vocabulary used: string commands `\institute` (sample.tex:3), `\instlogo` (4), `\schoolordepartment` (5), `\examname` (7), `\coursecode` (9), `\coursename` (10), `\timeduration` (11), `\maxmarks` (12), `\faculty` (13); kernel `\date` (2) read by the class's own `\maketitle` (16, redefined at cls:271); rule command `\bvrhrule[len]` (sample.tex:23, defined cls:188-190). Defined but not used by the main sample: `\abbrevinst`, `\instaddress`, `\cohort` (reserved, cls:136-157; README.md:61-63), `\bvrskipline` (cls:194; used only in the org sample, sample-org.tex:46), `\footnotenoless` (cls:300), the abbreviation macros `\eg \ie \cf \etc \vs \wrt \dof \etal` (cls:318-334). No abstract, keywords, sectioning, theorem, float, code or bibliography command is used.
