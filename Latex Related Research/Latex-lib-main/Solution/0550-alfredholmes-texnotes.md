# 0550-alfredholmes-texnotes: TeXNotes (LaTeX Zettelkasten, class `texnote`)

- Unverified: read from the source, not compiled.
- Source: Source/0550-alfredholmes-texnotes/ (origin: https://codeload.github.com/alfredholmes/TeXNotes/zip/refs/heads/main; licence: MIT)
- Kind: misc (a note-taking toolkit: one small class for atomic notes plus a Python manager; no journal, thesis or report layout)
- Lib: v4
- Engine: pdfLaTeX-compatible (`pdflatex` is the PDF renderer, manage.py:36; biblatex is run with biber, manage.py:479)
- Look carried by: zip-local (the whole look is `template/texnote.cls`: article plus amsthm theorem styles and hyperref colours; the sample preamble sets only `\title`)
- Class origin: zip-local (`texnote` is the author's own class; https://ctan.org/pkg/texnote is a 404, and the zip is an author's GitHub repository, not a publisher kit)
- Main file: pandoc/template.tex (the manifest's main; a pandoc template with `$title$` and `$body$`). Its hand-written LaTeX twin template/note.tex was read for the body constructs. Other samples: template/project.tex, template/preamble.tex, template/preamble_bak.tex, template/preamble_html.tex
- Read: main yes, zip-local classes and styles all (texnote.cls, all preamble*.tex, project.tex, make4ht.cfg, pandoc/*; of the Python tooling, manage.py was read only in its render, pandoc, newnote and newproject parts and `network.py`, `LatexZettel/*.py` were not read (`continuous_compile.py` was): they are not LaTeX)

## Verdict
The look itself is small and reduces: `texnote.cls` is `\LoadClass{article}` plus published packages, `amsthm` `\newtheorem` calls and `\hypersetup`, and its four helper macros expand inline into lib ways. It is still `no`. The manifest's main sample `pandoc/template.tex` cannot produce a document without pandoc, a Lua filter and a Python manager (EXTERNAL), the "Referenced In" section of every rendered note is generated by `manage.py` from a database and piped to pdflatex, and `template/project.tex` patches the internals of a published package with `\patchcmd`, which is irreducible. One new way is proposed (`struct.input`) for the tag-based file extraction the class defines.

## Blockers
- `EXTERNAL/body` the main sample is a pandoc template, `\title{$title$}` and `$body$`, filled by `pandoc -t latex --lua-filter=pandoc/filter.lua --template=pandoc/template.tex --metadata-file=pandoc/defaults.yaml --biblatex` (pandoc/template.tex:4, pandoc/template.tex:11, manage.py:348-349); the Lua filter writes the theorem environments, `proof` and equation labels from Markdown (pandoc/filter.lua:87-91, pandoc/filter.lua:121-123, pandoc/filter.lua:151-152)
- `EXTERNAL/body` the "Referenced In" section (`\section*{Referenced In}` plus an itemize of `\excref` items) is built in Python from a database and appended before `\end{document}`, and the whole document is piped to `pdflatex` on stdin; `notes/documents.tex` (the `\externaldocument` list the class imports) is appended by the script (manage.py:401-405, manage.py:434-437, manage.py:446, manage.py:51)
- `BESPOKE/preamble` `template/project.tex` (the export template copied by `newproject`, manage.py:119) edits a published package's internal macro: `\patchcmd{\CatchFBT@Fin@l}{\endlinechar\m@ne}{}`; it changes how transcluded text keeps its line ends, and a patch of package code fails W2 and W3 (template/project.tex:49-53; the same patch in template/preamble_bak.tex:62-66, which nothing loads)

Not counted as a blocker, recorded: the HTML route (`make4ht`, config/make4ht.cfg) needs tex4ht internals and is loaded only by the tool's `-c` flag (manage.py:36), not by the class or any sample; see Bespoke code.

## Class setting
- Class: `class.article` (reached through the zip-local wrapper `texnote`, template/texnote.cls:4); options: none (template/note.tex:1, pandoc/template.tex:1; `\ProcessOptions` at template/texnote.cls:73 has no declared options)
- Class-native vocabulary used: `\title`, `\maketitle` (pandoc/template.tex:4, pandoc/template.tex:9; template/note.tex:3, template/note.tex:6); no `abstract`, no `\author` (commented out, pandoc/template.tex:5), `\date` left at its default

## Lib changes
- New ways proposed: `struct.input` `catchfilebetweentags` (CTAN, LPPL 1.3, Florent Chervet, in TeX Live and MiKTeX per ctan.org/pkg/catchfilebetweentags, version 1.1; engine pdf). It extracts part of another file, delimited by strings or docstrip tags, and the class calls `\ExecuteMetaData[file]{tag}` (template/texnote.cls:64, loaded at :66; that `\ExecuteMetaData` belongs to this package is assumed from the load, the CTAN page names only `\catchfilebetweentags`). W1 published; W2 the file path and the tag are strings; W3 serves any note or chapter file that exposes tagged parts; W4 a `\usepackage` line plus one body call and `%<*tag>` comment lines. It is not `struct.input` (whole file by path) or `pg.standalone-pkg` (sub-files with their own preamble).
- Considered, no proposal: `slashed` (kept under `math.physics`), `ifthen` and `etoolbox` (helper packages with no printed effect).
- Existing ways used for the first time by the lib: none needed (the consolidator computes this)
