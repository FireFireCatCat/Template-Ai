## Verdict
The zip is the CTAN `novel` bundle itself, so the class is published (W1) and is one way, `class.novel`. The main sample `doc/novel.tex` defines no macro, no environment and no drawing: it loads the class and calls five class commands (`\SetHeadFootStyle`, `\SetTitle`, `\SetPDFX`, `ChapterStart`/`\ChapterTitle`/`\ChapterSubtitle`, `\scenebreak`) plus kernel text commands. Every component it uses has a lib way; one class-native metadata way is proposed. Verdict `yes` under the rubric's ruling for a look carried entirely by a published class; this is class-dimension evidence, not evidence for the component ways. Read it with the caveat in "Bespoke code": the class internals are large hand-written LuaLaTeX code that is irreducible if a published class were ever decomposed.

## Class setting
- Class: `class.novel` options: none in the main sample (doc/novel.tex:15, `% v. 2.2.`); `[v2,american]` in doc/extras/novel-example.tex:14. Options the class declares: `draft xml shademargins cropmarks cropview closecrop coverart sandbox unblock mtoff test revert v2` (lualatex/novel.cls:139-207). Trim size, margins, font size and lines per page are commands, not options (novel.cls:209-210).
- Class-native vocabulary used by the samples: `\SetHeadFootStyle{n}`, `\SetTitle`, `\SetAuthor`, `\theAuthor`, `\SetPDFX[intent]{standard}`, `ChapterStart[height][style]`, `\ChapterTitle[l|c|r]`, `\ChapterSubtitle[l|c|r]`, `\ChapterDeco[align,scale]`, `\decoglyph`, `\scenebreak`, `\nbs`, `\charscale[scale,x,y]`, `\frontmatter`, `\mainmatter`, `\cleartorecto`, `\nocle@rtoendtrue` (flag, developer only). Defined by the class but not used by the samples: `\SetTrimSize \SetMargins \SetMediaSize \SetLinesPerPage \SetFontSize \SetUnsafeZone`, `\SetParentFont \SetHeadFont \SetChapterFont \SetSubchFont \SetDecoFont \SetDropCapFont`, `\SetHeadJump \SetFootJump \SetEmblems \SetPageNumberStyle \SetVersoHeadText \SetRectoHeadText`, `\sceneline \scenestars \QuickChapter`, `\dropcap`, `\footnote \endnote \endnotetext \SetMarkerStyle`, `\InlineImage \FloatImage \WrapImage`, `toc`/`\tocitem`, `\sidebyside`, `parascale`, `legalese`, `\bigemdash`, `\midcase`, `\smcp \allsmcp`, `\lnum`.
- The class bans standard parts: `\maketitle \tableofcontents \listoffigures \listoftables \thebibliography \theindex \abstract` raise errors, `\part`..`\subparagraph` echo their argument, `\includegraphics`, float, table, list and `\caption` need `sandbox` (lualatex/novel-LayoutSettings.sty:343-381; novel-Images.sty:163-170); `geometry`, `fontenc`, `inputenc`, `biblatex`, `booktabs`, `makeidx`, `bookmark`, `pdfx`, `hyperxmp` and others are blocked (novel.cls:516-532).

The four informational rows are the internals of a published CTAN class. By the rubric's W1 and "class setting" rules they are one way and not a blocker. If the project ever required published classes to be decomposed, these rows would become `BESPOKE/class` (irreducible: computed layout, `\parshape`, Lua, PDF object writing) and this zip would turn to `no`. Outside TeX: `doc/extras/novel-scripts.zip` (shell and batch image converters, listed only) is optional and only for images and `coverart` PDFs; unprocessed images give a warning (novel-Images.sty:536-547) and only `\ScriptCoverImage` under `coverart` errors (Images:132-144), so it is not an `EXTERNAL/package` blocker for this sample, which has no images.

## Lib changes
- New ways proposed: `meta.class-native` (section meta; the class's own PDF metadata and print-conformance commands `\SetTitle \SetAuthor \SetPDFX[intent]{standard}`; engine: lua for novel, the way itself is the engine of its class). W1: documented interface of the CTAN class `novel`. W2: strings plus an output-intent name and a standard chosen from a closed list (`X-1a:2001 X-1a:2003 X-3:2002 X-3:2003 off`, FileData:112-158). W3: serves the metadata component of any class that exposes its own metadata commands, parallel to `hf.class-native`, `front.class-native`, `abs.class-native`, `head.class-native`, `thm.class-native`. W4: three preamble lines. No existing home: `meta.pdfx` is the `pdfx` package, which this class blocks (novel.cls:517); `meta.hyperxmp` is blocked (519); `meta.hyperref` title and author options are disabled by the class (novel-pdfx.sty:487-494); `meta.documentmetadata` is the kernel `\DocumentMetadata`, which the class does not use.
- Existing ways used for the first time by the lib: none needed (the consolidator computes this). Note for the consolidator: `page.class-options` is used here for a class that sets trim size and margins by commands and defaults rather than by options; if more classes do this, a `page.class-native` split may be worth proposing.
