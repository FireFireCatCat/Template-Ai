## Lib changes
- New ways proposed: `NEW:form.sf298` (`sf298`, CTAN, TeX Live, MiKTeX, LPPL 1.2; Cochran and Rochford; v1.3 of 2016-07-07; pdf): the U.S. Government Standard Form 298, "Report Documentation Page", filled in from string fields. `\usepackage[config|noconfig, nofloatlongboxes|floatlongboxes]{sf298}`; 27 field commands (`\ReportDate` `\ReportType` `\DatesCovered` `\Title` `\ContractNumber` `\GrantNumber` `\ProgramElementNumber` `\ProjectNumber` `\TaskNumber` `\WorkUnitNumber` `\Author` `\PerformingOrg` `\POReportNumber` `\SponsoringAgency` `\Acronyms` `\SMReportNumber` `\DistributionStatement` `\SupplementaryNotes` `\Abstract` `\SubjectTerms` `\ReportClassification` `\AbstractClassification` `\PageClassification` `\AbstractLimitation` `\NumberPages[*]` `\ResponsiblePerson` `\RPTelephone`), offsets `\LeftShift{bp}` `\DownShift{bp}`, body `\ReportDescription` (alias `\MakeRptDocPage`) and `\GeneralInstructions{typesize}`; it loads `multicol` and `fancyhdr` unconditionally (1132-1149) and `totpages` when found (1116-1118). W1: on CTAN, in TeX Live and MiKTeX, and the zip is its CTAN release. W2: values are strings, two option pairs, big-point shifts, one size-environment name and a config file that only sets the same commands. W3: it serves the report documentation page of any report delivered under a U.S. Government contract, not one document (fixed shapes with strings as values, as `cal.kalender` has a fixed grid and one year). W4: one load line, field commands in the preamble, one body call per page. Considered: folding it into a class-like way for one-agency forms (the v3 and v6 precedent for one-institution add-ons); a `form.` line was chosen because it is not a class and sits under `class.article` here, and the consolidator may fold it.
