- Source: Source/0246-erdc/ (origin: https://mirrors.ctan.org/macros/latex/contrib/erdc.zip; licence: LPPL 1.3, erdc.dtx:6-8)
- Kind: report
- Lib: v3
- Engine: pdfLaTeX-compatible (erdc.dtx:161-163 says the class works with latex and pdflatex; the fonts are a missing asset, see below)
- Look carried by: class (the whole cover, title page, headings, lists of contents and running heads are in erdc.dtx:561-1918; sample.tex adds only `lipsum` and `url`, sample.tex:2, and content)
- Class origin: ctan (ctan.org/pkg/erdc: class, LPPL 1.3, v1.1, by Boris Veytsman; the zip is the CTAN source `erdc.dtx` + `erdc.ins`, the `.cls` is generated by DocStrip, erdc.ins:14-15)
- Main file: sample.tex (other samples: none; erdc.dtx is the class source and its own documentation, driver at erdc.dtx:547-560)
- Read: main yes, zip-local classes and styles all (erdc.dtx read in full, 1928 lines; no `.cls`/`.sty` file is in the zip)
- Missing assets: the fonts Microsoft Georgia and ITC Franklin Gothic are not shipped (erdc.dtx:118-121, 656) and are commercial; ctan.org/pkg/mathgifg says the TrueType files must be converted to Type 1 once (it names `ttf2pt1`). `nola` and `red_corps_castle2` (.eps and .pdf) are shipped.

## Verdict
yes. The look is carried by one published class, `class.erdc` (CTAN), and the sample adds no macro, environment or counter of its own: it calls the class's own front-matter commands, kernel sectioning, lists, equations, tables, figures and a BibTeX bibliography, each of which has a lib way. The class's internals (a boxed red cover banner, redefined `\@makechapterhead`, `\l@chapter`, hand-rolled `\if@appendix` counters) are irreducible code by the rubric's test, but they are published code, so they are the class way and not bespoke (they would be `BESPOKE/class` and `ART/class` only if the class were judged zip-local). One judgement call: the Georgia/Franklin Gothic fonts need a one-time TrueType-to-Type-1 conversion outside TeX; I read it as the rubric's non-blocking "missing assets", because no external tool runs when the document is compiled, not as `EXTERNAL/package` (erdc.dtx:656 loads `mathgifg` unconditionally).

## Blockers
none

## Class setting
- Class: `class.erdc` options: none in the sample (sample.tex:1). The class accepts `8pt`..`12pt` as warnings only (erdc.dtx:572-579), passes every other option to `report` (erdc.dtx:585), and itself loads `report` with `12pt,twoside` (erdc.dtx:594).
- Class-native vocabulary used: `\frontmatter` `\mainmatter` `\appendix`; `\reportnum` `\program` `\title` `\subtitle` `\date` `\author` + `\and` + `\affiliation` (one block per affiliation) `\coverart` `\reporttype` `\additionalinfo` `\contractnum` `\monitoredby` `\maketitle` (sample.tex:5-60); `abstract` environment (sample.tex:44-46); `\tableofcontents` and `\listoffiguresandtables` (sample.tex:62,64); `\chapter` `\section` `\subsection`. Defined by the class and not used in the sample: `\laboratory` (commented, sample.tex:7), `\distribution` (commented, sample.tex:38-40), `\disclaimer` (sample.tex:48), `\preparedfor` (sample.tex:50-51), `\specialchapter`, `\listoffigures`, `\listoftables` (erdc.dtx:931,1113,1177,1121,1607,1774,1784).
- Note: the manual says sections and subsections are not numbered (erdc.dtx:416-417); the code numbers them while `secnumdepth` is at least 1 (erdc.dtx:1528-1539, 1570-1581), so the manual is stale and the code is what is read here.
