## Verdict
The look of the main sample sits entirely in the published bundle (`class.tudscrdoc`, `tudscrfonts`, `dtx.doc`), and the sample adds only option settings, a few KOMA title fields and a preamble of package loads, so the component side would reach `yes`. The answer is `no` because the sample cannot produce its printed output with TeX alone. The sample loads `tudscr-gitinfo`, which runs `git log` through a shell pipe to feed the revision stamp in every page footer. The class option `xindy` has `tudscrdoc` run `texindy` through `\ShellEscape` for the index and change history. A wrong `yes` costs more than a wrong `no`, and both blockers degrade only quietly (warnings, empty back matter), so they are recorded as EXTERNAL.

## Blockers
- `EXTERNAL/class` option `xindy` (sample line 10) makes `tudscrdoc` write a `.xdy` style (source/tudscr-texindy.dtx:106-468) and run `texindy` via `\ShellEscape` at class load on the previous run's `.idx` and `.glo` (source/tudscr-doc.dtx:1401-1489, ShellEscape at 1463-1476); without it the class runs `makeindex` the same way (source/tudscr-doc.dtx:1494-1503); `shellesc` and `pdftexcmds` are loaded unconditionally (source/tudscr-misc.dtx:741-742); the author notes "shell-escape raus, via makefile" as an open ToDo (source/tudscr-doc.dtx:1390); the Index and Change history parts of `\PrintBackMatter*` (source/tudscrsource.tex:101) exist only if this tool run happened
- `EXTERNAL/preamble` `\RequirePackage{tudscr-gitinfo}` (source/tudscrsource.tex:9) calls `git log -1` as a pipe input when `\pdf@shellescape=1` (source/tudscr-gitinfo.dtx:257-286) and writes `tudscr-gitinfo-ver.aux` at the end (source/tudscr-gitinfo.dtx:296-324); the values print in each page footer (source/tudscr-doc.dtx:224-237); without git it warns and falls back to the `\ProvidesFile` data (source/tudscr-gitinfo.dtx:204-205); the zip carries no `.git` directory
- `BESPOKE/class` counted only if `class.tudscrdoc` is judged zip-local (the CTAN page names no `tudscrdoc`, but README.md:142-153 and `tudscr.ins` ship it): the class patches `doc.sty` and `ltxdoc` internals, `\@docinclude` (source/tudscr-doc.dtx:221-223, 1612-1632), `\@NewDocElement` (328-353), the special-index macros (445-518, 581-697) and `\changes@` (1076-1144), which no lib way can express; as a published class it is not a blocker

## Class setting
- Class: `class.tudscrdoc` options: `english`, `ngerman`, `xindy` (source/tudscrsource.tex:10); the class passes `toc=left,fontsize=10pt,parskip=half-` to `scrartcl` (source/tudscr-doc.dtx:81), swaps `article` for `scrartcl` under the `LoadClass` it receives (source/tudscr-doc.dtx:87-101) and then loads `ltxdoc` (source/tudscr-doc.dtx:116), so `class.ltxdoc` and `class.scrartcl` are the layers underneath
- Class-native vocabulary used: `\subject` `\subtitle` `\addtokomafont` (KOMA, source/tudscrsource.tex:23-28); `\ToDo{text}[tag]` (source/tudscrsource.tex:66-72; source/tudscr-doc.dtx:1536-1572); `\DocInclude{file}` ×21 (source/tudscrsource.tex:75-98); `\PrintBackMatter*` (source/tudscrsource.tex:101; source/tudscr-doc.dtx:1594-1603); inline `\cls` `\app` `\file` `\cs` (source/tudscrsource.tex:57, 66, 68; source/tudscr-doc.dtx:1815-1826); `\GitHubBase` (source/tudscrsource.tex:21; source/tudscr-misc.dtx:1190); `\TUDScript` `\TnUD` `\CD` (source/tudscr-misc.dtx:1133-1137); `\TUDScriptContactTitle` (source/tudscr-misc.dtx:1267); in the included files the doc elements `macro` `environment` `option` `length` `counter` `field` `parameter` and `\changes` (source/tudscr-doc.dtx:721-732)
- Vocabulary of the bundle's user classes (read in examples, not in the main sample): `class.tudscrreprt` (source/doc/examples/thesis.tex:1; dissertation.tex:1-4) with `\faculty` `\department` `\institute` `\chair` `\subject{master}` `\graduation` `\matriculationnumber` `\supervisor` `\professor` `\thesis{diss}` `\defensedate` `\referee` `\TUDoption{abstract}{...}` `\nextabstract` (thesis.tex:11-35; dissertation.tex:15-37); the CD classes are `tudscrartcl` `tudscrreprt` `tudscrbook` `tudscrposter` (README.md:35-45)
