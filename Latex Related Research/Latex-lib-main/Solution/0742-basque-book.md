## Verdict
The zip is the DocStrip source of `basque-book`, a class published on CTAN (LPPL 1.2), so it is one way, `class.basque-book`; an emitter writes `\documentclass[<book options>]{basque-book}` and copies no macro logic. The class is a copy of the kernel `book` class with Basque order of number and name in headings and captions, Basque name strings, dot-ended numbers and `\today` bound to `basque-date`. Because the class is published, none of its redefinitions is bespoke under the rubric; they are still listed below with the reduction each would have to component ways, and none is irreducible. The zip's two documents are plain `ltxdoc` documentation (reducible to lib ways). This is evidence about the class dimension, not about the component ways.
