## Class setting
- Class: `class.script` (report/book-like, has `\chapter`), `class.script_s` (article-like, no `\chapter`), `class.script_l` (letter). Options of `script` and `script_s`: `10pt` `11pt` `12pt` `18pt` (`18pt` is experimental, script2e.txt:8-9), `a3paper` `a4paper` `a5paper` `a6paper` and the landscape forms `a3lpaper` `a4lpaper` `a5lpaper` `a6lpaper`, `oneside` `twoside`, `draft` `final`; default `a4paper,12pt,oneside,final` (script.cls:20-41; script_s.cls:20-41). Options of `script_l`: `10pt` `11pt` `12pt` `oneside` `twoside` `draft` `final`, no paper option, default `12pt,oneside,final` (script_l.cls:25-33).
- Class-native vocabulary (defined, none used since there is no sample):
  - `script` and `script_s`: `\typearea[bcor]{div}` and `\areaset[bcor]{width}{height}` (script.cls:65-66, 117-118), `\headseplineon/off` `\headincludeon/off` `\footseplineon/off` `\footincludeon/off` (script.cls:46-59), `\titlehead` `\subject` (and, in `script` only, `\extratitle` `\publishers` `\uppertitleback` `\lowertitleback` `\dedication`, script.cls:309-322), `\maketitle[firstpagenumber]` (script.cls:323-324), `\abstracton/off` (script.cls:377-379), `\part` `\chapter` `\addchap` `\minisec` (script.cls:389-456), `\addsec` (script_s.cls:379-382), `labeling` environment (script.cls:292-298), `\marginline` (script.cls:300-302), font hooks `\sectfont` `\captfont` `\descfont` `\headfont` `\pnumfont` and the sized bold sans switch `\sfb` (script.cls:668-672).

- Load risks, recorded and not tested: script.cls:25-26 and script_s.cls:25-26 declare `\newdimen\paperwidth` and `\newdimen\paperheight` themselves, and a current LaTeX kernel already provides those registers, so this may raise an error; script_s.cls:7 says `\ProvidesClass{script}` (not `script_s`), which gives a name-mismatch warning at most; with the `18pt` option `\@ptsize` is 8 and the `\ifcase` at script.cls:164 (script_s.cls:164) has no branch for it, so `\typearea` is never called; script18.sty:7 pairs the 12pt size selector `\xiipt` with 17pt leading (reads as an unfinished option). script2e.txt:11-12 says the original Script package must be present because this is a patch archive; no file named by the loaded code (`script1\@ptsize.sty`, `oldlfont.sty`) is missing from the zip and the LaTeX base, but the original package's file list is not given, so this is not certain.
