## Verdict
yes. The zip is the CTAN source of a published class, `exam-n` (CTAN, TeX Live, MiKTeX, LPPL 1.3c), and the two templates (template-question.tex, template-master.tex) add nothing to it but option values (`compose`, `siunitx`), data strings (`\exambanner`, `\rubric`, ...) and body content in the class's own vocabulary, so an emitter writes `\documentclass[...]{exam-n}`, the setter commands and the class's own environments and copies no macro logic. No package the class loads needs a tool outside TeX, and there is no TikZ or other artwork. This verdict rests on the pilot ruling that a published class counts as one way (W1): the class internals (custom `\maketitle`, mark boxes, `\everypar` question numbers, non-floating figures) would be irreducible BESPOKE/class if the class had to be rebuilt from other ways, and are listed under Bespoke code for that reason. It is evidence about the class dimension, not about the component ways.
