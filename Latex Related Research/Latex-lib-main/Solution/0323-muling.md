## Verdict
The zip is the DocStrip source of `muling`, a class published on CTAN, so it is one way, `class.muling`, which loads `class.book` (muling.dtx:320). An emitter writes `\documentclass[digital,lof]{muling}` plus the class's three native commands and copies no macro logic, so this is evidence about the class dimension, not about the component ways. Nothing in the zip is unpublished, so nothing counts as bespoke under the rubric; the class's internal macros are still decomposed below and each one reduces to lib ways, so the verdict would not change if the class were treated as unpublished. Everything the class loads is a lib way, including the biber and `makeglossaries` toolchains that `bib.biblatex-biber` and `idx.glossaries` already carry; the only cost is the LuaLaTeX engine and two font files the zip does not ship.

## Class setting
- Class: `class.muling` options: `digital` (forces `oneside` on `book`, muling.dtx:305; default is `book`'s own twoside), `lof` (sets `\lofttrue`, :306-307). `\ProcessOptions` is called without a forwarding `\DeclareOption*` (:308), so any other option (`a4paper`, `12pt`) would be unknown as read; paper size and type size stay at `book`'s defaults. Loads `class.book` with no options besides `oneside` (:320).
- Class-native vocabulary used: `\subtitle{}` `\shorttitle{}` `\supervisor{}` (dtx:329-340, example :257-264), the redefined `\maketitle` (:417-525) that prints the boxed title page, the table of contents, the abbreviations glossary, the list of tables and the Declaration page in one call, with `\title` `\author` `\date` kept from the kernel; preloaded-package vocabulary used by the example: `\pex` `\xe` (expex, :270-272, :351), `forest` and `\head` (:275-291, :348), `\enquote` (csquotes, :170, :498), leipzig abbreviation macros such as `\Nom` (:157-160), `\printglossary` (:479).
