## Verdict
no. The only class the sample loads is doc/scrguide.cls (`\documentclass[english]{scrguide}`, doc/scrguide-en.tex:26), a 3033-line internal documentation class on top of `scrbook`. It is irreducible: it hand-rolls a box-measuring `Declaration` environment, a `desclist` table that breaks pages by comparing `\pagegoal` with `\pagetotal`, an index-group stack, a change-log writer, label and anchor machinery over hyperref internals, and a `picture`-drawn page frame (`ShowOutput`). The guide body then calls these private macros about 400 (`Declaration`), 150 (`Example`) and 550 (`\ChangedAt`) times. The look cannot be rebuilt from lib ways plus parameters. The other samples in the zip (remarkbox, note column, letters, the published KOMA classes) are easy yes cases on their own, but the main sample decides.

## Blockers
- `BESPOKE/class` `Declaration` environment: `lrbox` plus `\catcode` change, saved box, penalty-based keep-together test, rebinds about 15 markup commands (doc/scrguide.cls:1421-1523)
- `BESPOKE/class` `desclist`/`desctabular`/`desctable`: rows measured in boxes, `\pagegoal`/`\pagetotal` comparison, manual `\newpage`, repeated caption and foot boxes, page-parity flag (doc/scrguide.cls:1803-2037, worker 1857-1906)
- `BESPOKE/class` index machinery: push/pop `\@IndexStack`, `\BeginIndex`/`\EndIndex`/`\CloseIndex` with penalty and skip preservation, `\DefineSingleIndex`/`\DefineDoubleIndex`/`\DefineTripleIndex`, `\IndexSeeAt` (doc/scrguide.cls:2660-2993)
- `BESPOKE/class` label and anchor system for macros, options, lengths, counters, variables, hooks: `\Hy@MakeCurrentHref` plus `\Hy@raisedlink` anchors, label base switching (doc/scrguide.cls:768-1222, 1329-1403)
- `BESPOKE/class` change log: `\ChangedAt` with year/month arithmetic and `\glossary` writes, `thechangelog`, translator list through the aux file, newest-file date through `\@ifl@t@r` and aux (doc/scrguide.cls:440-639, 1709-1778)
- `BESPOKE/class` patches of hyperref and kernel internals: `\autopageref` via `\hyper@@link` (2287-2320), `\url@` redefinition for `CTAN://` (2252-2259), `\@notonlypreamble` (450-475), `\ProvidesFile` hook (527-538)
- `BESPOKE/class` title page margins swapped around `\maketitle` with `\@twosidetrue` (free version, doc/scrguide.cls:303-313)
- `ART/class` `ShowOutput` draws a torn-page frame with `picture` and `\qbezier` around a scaled box (doc/scrguide.cls:1559-1594); `XmpTopPage`/`XmpBotPage` draw page outlines with `picture` (doc/scrguide.cls:1619-1652; unused in the English chapters)
- `BESPOKE/body` the chapters depend on the private macros above and on `\LoadCommonFile`, which `\input`s `common-<name>-<lang>.tex` into several chapters with a label-base switch (doc/scrguide.cls:371-390; 51 uses in doc/*-en.tex); `\lalias` rewrites `r@` label entries with `\expandafter` chains (doc/linkalias.tex:30-61); `\iffree` switches (doc/scrguide.cls:253)

Not counted as a blocker, recorded: the full multi-part index needs an external perl splitter (comment at doc/scrguide.cls:2442), but it is guarded by `\IfFileExists{\jobname-gen.ind}` (2458) and the shipped free build (README.md:538) uses one index, so no tool outside TeX/makeindex/bibtex is needed for the shipped build.

## Class setting
- Reading scope: driver doc/scrguide-en.tex and body doc/scrguide-body.tex in full; chapters sampled only (introduction-en, preface-en, authorpart-en, scrbookreportarticle-en lines 20-280, terms-en lines 20-130 and 385-465, heads of the figure files; about 60k lines of chapter text not read); doc/scrguide.cls read except the keyword list at lines 2157-2199; koma-script-source-doc.dtx lines 240-470 plus a code outline; the about 40 implementation `.dtx` files of the published KOMA classes and packages, and scrdocstrip.tex, scrstrip.inc, scrmain.ins, were not read beyond heads and guard structure.
- Class origin reasoning: the zip is the author's own CTAN release and lists scrguide.cls in MANIFEST.md:88, so it is "published" under the pilot ruling, but the class is internal (absent from the README's list of released classes), serves a single document and carries its look in code. It fails W2 and W3, so `class.scrguide` is not accepted as a way and its code is counted as BESPOKE/class.
- Class: `class.scrbook` options: bibliography=totoc, index=totoc, captions=tableabove, headings=small, headings=optiontoheadandtoc, version=last (passed with `\PassOptionsToClass`, doc/scrguide.cls:114-121), language option `english`; base loaded by `\LoadClassWithOptions{scrbook}` (doc/scrguide.cls:154). The sample's own `\documentclass{scrguide}` is the bespoke wrapper (BESPOKE/class above).

## Lib changes
- New ways proposed: `note.mparhack` `mparhack` (CTAN; pdf; load-only fix for margin-note side and placement). W1: on CTAN. W2: no options, a load-only switch like the accepted `pg.emptypage` and `cols.balance`. W3: any document with margin notes. W4: one `\usepackage{mparhack}` preamble line. It is loaded unconditionally by scrguide.cls:219 and the guide sets about 550 margin notes through `\marginnote`.
- Considered and not proposed: scrlayer `\DeclareNewLayer` (mapped to `hf.scrlayer-scrpage`, the package that builds its page styles from layers); `babelbib` (mapped to `bib.bibtex-bst` with `fixlanguage`); `scrdate`/`scrtime`/`engord` (loaded, never exercised); `scrguide` as `class.scrguide` (published only nominally, fails W2 and W3 because it serves one document and its look is code, not option values).
- Existing ways used for the first time by the lib: none needed (the consolidator computes this)
