## Verdict
Both samples use a published class (CTAN package `kdgdocs`, confirmed with one read of ctan.org/pkg/kdgdocs: two classes, LPPL 1.3, in TeX Live) and add only class options, `babel` and the class's tag commands, so an emitter writes `\documentclass[...]{kdgcoursetext}` or `{kdgmasterthesis}` plus strings and kernel `book` commands, with no copied macro logic. The class code in the .dtx is not zip-local to the sample; it is the published class itself, so it counts as one class way each (rubric pilot ruling: look carried by a published class). Judgment call, stated openly: read as stand-alone code instead of as a published class, the title pages (TikZ polygon and absolutely placed nodes inside a shipout overlay, kdgdocs.dtx:1031-1078 and 1115-1151) would be `ART/class` and the `\diploma` lookup (kdgdocs.dtx:870-880) would be a conditional that drives printed text, and the answer would then be `no`. Missing asset, not a blocker: Verdana font files are proprietary and not shipped.

## Blockers
none (the class-internal title-page artwork is carried by the published class way, see Bespoke code)

## Class setting
- Class: `class.kdgcoursetext` options: `a4paper,11pt,oneside,openright,english,copyright` (kdgcoursetext-example.tex:25). The class declares only `copyright` (kdgdocs.dtx:615-616), executes `a4paper,11pt,final,oneside,openright` (kdgdocs.dtx:621), processes options, then `\LoadClassWithOptions{book}` (kdgdocs.dtx:622-623).
- Class: `class.kdgmasterthesis` options: `a4paper,11pt,twoside,openright,english,copyright` (kdgmasterthesis-example.tex:25). It declares no `copyright` option (the declaration at kdgdocs.dtx:614-617 sits under the `ct` guard) and has the same defaults and `book` base (kdgdocs.dtx:620-624).
- Class-native vocabulary used, kdgcoursetext: `\title` `\subtitle` `\author` (kdgcoursetext-example.tex:30-32), `\courseversion` `\versionyear` `\versioncomment` (:34-36), `\professori` `\professorii` `\professoriii` (:38-40; `\professor` and `\professoriv` also exist, kdgdocs.dtx:805-809), `\programme` (:42), `\coursecodei` `\coursecodeii` `\coursecodeiii` (:43-45), `\academicyear` (:47), `\titlepagepicture` (:49), `\copyrightnotices` (:51-54), `\maketitle` (:59); also declared but not used by the sample: `\department`, `\departmentacronym` (kdgdocs.dtx:722-735).
- Class-native vocabulary used, kdgmasterthesis: `\title` `\author` (kdgmasterthesis-example.tex:30-31), `\promoteri` `\promoterii` `\promoteriii` (:33-35; `\promoter` and `\promoteriv` also exist, kdgdocs.dtx:824-828), `\academicyear` (:37), `\diploma` (:38, one of BCH CH EI-AE EI-ICT EM-AE EM-AU EM-EM, kdgdocs.dtx:873-879), `\defenselocation` (:39), `\defensedate` (:40), `\maketitle` (:45).
- Inherited `book` vocabulary used: `\frontmatter` `\mainmatter` `\backmatter` `\appendix` `\chapter` `\chapter*` `\section` `\subsection` `\tableofcontents` (kdgcoursetext-example.tex:61-66,75,77,120,170).
