# 0758-osa: OSA journal manuscript kit (osajnl.sty for JOSA A, JOSA B, Applied Optics, Optics Letters; sibling kits for Optics Express and J. Optical Networking)

- Unverified: read from the source, not compiled.
- Source: Source/0758-osa/ (origin: https://mirrors.ctan.org/macros/latex/contrib/osa.zip, CTAN package `osa`, "Macros for Optical Society of America Journals, etc.", maintainer Optical Society of America; licence: not established, the CTAN page states none and shows only a 2003 OSA copyright line)
- Kind: journal
- Lib: v6
- Engine: pdfLaTeX-compatible (journals/osajnl.sty:36-40 branches on `\pdfoutput` and loads `graphicx` with `pdftex`; the sample's hyperref `dvips` driver option, journals/OSAstyle_pdf.tex:37, and its EPS figure point to a latex+dvips route, recorded below as a parameter and an asset, not as a blocker)
- Look carried by: class (journals/osajnl.sty, a publisher house-style package from the CTAN `osa` bundle, treated as the class-like way `class.osajnl`; the sample adds only content and one hyperref option list)
- Class origin: ctan
- Main file: journals/OSAstyle_pdf.tex (other samples: journals/OSAstyle.tex, journals/OSAtemp.tex, optics_letters/OLpagelength.tex, optics_express/OpEx_style.tex, optics_express/OpEx_temp.tex, optical_networking/JONXML.TEX)
- Read: main yes, zip-local classes and styles all (osajnl.bst outlined by a declaration count only, not read; its four copies have three different contents by hash, journals/ one, optics_express/ and optics_letters/ identical, optics_letters/mac/ one)

## Verdict
yes. The main sample is `article` plus the published OSA package `osajnl` plus `multicol` and `hyperref`; every title, abstract, OCIS, heading, caption and bibliography look comes from `osajnl.sty`, which is on CTAN and kept by OSA (README:1-12, journals/README:1-4), so it is a published way and not bespoke code. Everything the sample adds in the body is kernel LaTeX (sectioning, `enumerate`, `equation`, `eqnarray`, `tabular`, `figure`, `verbatim`, `thebibliography`). No artwork defines the template; the only picture is an EPS figure, which is content.

## Blockers
none

## Class setting
- Class: `class.article` options: `letterpaper,11pt` (journals/OSAstyle_pdf.tex:35). Look-carrying house-style package: `class.osajnl` (journals/OSAstyle_pdf.tex:36, no options; the only option it declares is `copyedit`, journals/osajnl.sty:278-281, not used by the sample). Written as a class way by the precedent of other publisher house-style add-ons that the lib folded into class ways.
- Class-native vocabulary used (class.osajnl): `\title{}` `\author{}` `\address{}` `\email{}` (journals/OSAstyle_pdf.tex:41-62, each prints at once, journals/osajnl.sty:77-81), `abstract` environment (journals/OSAstyle_pdf.tex:64-71), `\ocis{}` (journals/OSAstyle_pdf.tex:73), `\maketitle` as a no-op (journals/OSAstyle_pdf.tex:77, journals/osajnl.sty:88), `thebibliography` with `\bibitem` (journals/OSAstyle_pdf.tex:502-561), journal-name macro `\opex` (journals/OSAstyle_pdf.tex:419, 558; defined journals/osajnl.sty:234). Aliases the package defines and the text names but the sample body does not call: `\pacs` and `\affiliation` (journals/OSAstyle_pdf.tex:130-132), `\citeonline` and `\onlinecite` (journals/OSAstyle_pdf.tex:339-340); defined at journals/osajnl.sty:82, 89, 90 and the `\citeonline` command itself comes from `overcite`. `\affil` (journals/osajnl.sty:79) and `\homepage` (journals/osajnl.sty:63-64) are defined and unused.

## Lib changes
- New ways proposed: none. Considered and not proposed: `natbib` with its `super` option for the superscript callouts (not used: the package loaded is `overcite`, held by `bib.cite-pkg`); the `overcite` source was not read, it is not in the zip (journals/README:6-8).
- Existing ways used for the first time by the lib: none needed (the consolidator computes this)
- Notes: ctan.org/pkg/osa was read once (title, maintainer OSA, no licence stated, listed in MiKTeX). `geometry` and `overcite` are not bundled (journals/README:6-8) and are on CTAN. The hyperref `dvips` driver option (journals/OSAstyle_pdf.tex:37) is a parameter of `meta.hyperref` that a pdfLaTeX emitter would change. If a reviewer rules `osajnl.sty` zip-local instead of published, the reductions in the Bespoke code table become the test; I judge them reducible but did not verify their equivalence.
