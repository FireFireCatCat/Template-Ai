- Kind: cv
- Lib: v2
- Engine: pdfLaTeX-compatible (the author's Justfile calls `latexmk -pdf`, templates/cv/Justfile:3; no fontspec or Lua; the APA, report and workshop templates also need the biber backend)
- Look carried by: zip-local (each template's look sits in its own zip-local class, e.g. templates/cv/cv-sizuhe.cls; the samples add only `babel`, doc-variable strings and a few load-only packages)

- Main file: templates/cv/main.tex (other samples: templates/doc_apa/main.tex, templates/letter/main.tex, templates/report/main.tex, templates/workshop/main.tex)
- Read: main yes, zip-local classes and styles all

## Verdict
Five zip-local classes (cv, apa, letter, report, workshop) are each `\LoadClass[10pt]{article}` plus published packages, `\titleformat`, `\fancypagestyle`, `\captionsetup` and `\newcommand` macros that only compose lib ways (minipage, tabularx, fancyhdr, titlesec, rules, spacing), and the `\ifnum`, `\ifthenelse` and `\newif` switches choose between fixed layouts and are resolved when an emitter writes one branch. No output routine, `\halign`, expl3/Lua layout code or kernel-internal redefinition exists, so the answer is yes. The five TikZ overlays (CV photo, letter signature, letter page-edge bar, report heading band, report header logo) place an image or fill a plain coloured rectangle, and each reduces to `pg.textpos`, `bg.eso-pic` with `sp.rule`, or `head.titlesec` with `box.fancybox`; they are the borderline items and are listed in "Bespoke code". Two new ways are proposed (`cols.vwcol`, `font.serif-pkg`).

## Class setting
- Class: `class.article` options: `10pt` (every wrapper class calls `\LoadClass[10pt]{article}`: templates/cv/cv-sizuhe.cls:27, templates/doc_apa/cls/apa-sizuhe.cls:31, templates/letter/cls/letter-sizuhe.cls:27, templates/report/cls/report-sizuhe.cls:31, templates/workshop/cls/workshop-sizuhe.cls:31); the wrapper's own options are `cv01`/`cv02` (templates/cv/main.tex:1-2) and `apa01`/`apa02` (templates/doc_apa/main.tex:2-3), which only select a macro set and need no lib way.
- Class-native vocabulary used: none from `article` beyond `\section` family, `itemize`, `figure`, `\caption`; the wrapper vocabulary (`\maketitle` with 8, 1 or 0 args, `\cvSection`, `\addSectionContent`, `\question`, `\setlogo`, `\makesignature`, `\docTitle`...) is zip-local and is reduced below.

- New ways proposed:
  - `cols.vwcol`: `vwcol` package (CTAN, version 0.2, TeX Live; ctan.org/pkg/vwcol read), engine pdf; environment `vwcol[widths={..}, sep=.., rule=.., indent=..]` typesets unequal-width text columns on one page. W1 on CTAN; W2 keys are lists and lengths; W3 serves any unequal-column block; W4 a preamble `\usepackage{vwcol}` plus a body wrapper around the column contents (templates/doc_apa/cls/apa-sizuhe.cls:37, 189-217). `cols.multicol` is equal-width, `cols.paracol` is parallel text, `cols.minipage` is fixed boxes.

W1 CTAN (ctan.org/pkg/sourceserifpro read, version 2.0); W2 options; W3 any serif family; W4 `\usepackage[default,light]{sourceserifpro}` (templates/doc_apa/cls/apa-sizuhe.cls:45).
