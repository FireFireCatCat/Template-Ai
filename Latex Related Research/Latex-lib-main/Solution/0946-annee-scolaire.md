## Verdict
The zip is the CTAN package `annee-scolaire` (LPPL 1.3c, Yvon Henel) with its documentation source. As a published package it is one way (preamble line with key options, three inline commands) and the rest of the sample is `class.l3doc` plus kernel and published packages, all of which map. The answer is `no` because the user guide redefines the package's presentation hook with expl3 code that dispatches on an integer to pick the format of each printed year (annee-scolaire.dtx:500-510). That is a hand-written conditional that drives what is printed, written in the zip itself, with no lib way to carry it. It is one body-scope construct; without it every component maps.

## Blockers
- `BESPOKE/body` `\RenewDocumentCommand{\AnneeScolairePresentation}{ o m }` whose body is an expl3 `\int_case:nn` on the optional argument (1 bold arabic, 2 lower roman, 3 italic arabic, 4 upper Roman), executed in a group in the user guide (annee-scolaire.dtx:498-513); the same code printed as a listing at annee-scolaire.dtx:478-493 is content.
