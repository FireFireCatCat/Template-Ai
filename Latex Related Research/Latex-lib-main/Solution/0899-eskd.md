# 0899-eskd: eskd (Russian ESKD / GOST 2.104-68 stamped-frame documents)

- Unverified: read from the source, not compiled.
- Source: Source/0899-eskd/ (origin: https://mirrors.ctan.org/macros/latex/contrib/eskd.zip; licence: LPPL 1.2 per the manifest; README:10-13 says 1.1 or later)
- Kind: report (engineering design document: ESKD page frames with a stamp table, a title page and a sheet of changes)
- Lib: v6
- Engine: pdfLaTeX-compatible (the class loads only 8-bit packages: inputenc koi8-r, fontenc T2A, babel russian, pscyr; no fontspec). The `pscyr` Type 1 font pack is not shipped and not on CTAN (see Class setting)
- Look carried by: class (example.tex sets only class options and string fields; the frames, stamps, title page and change sheet are all produced inside the published class `eskd`)
- Class origin: ctan
- Main file: example.tex (other samples: the package manual, driver at eskd.dtx:2-54 plus the documentation text of eskd.dtx; no `.cls` is shipped, `eskd.cls` is generated from `eskd.dtx` by `eskd.ins:6-8`)
- Read: main yes, zip-local classes and styles all (`eskd.dtx` in full, `eskd.ins`, `README`; `eskd.ind` and `eskd.pdf` are generated manual output and were not read)

## Verdict
Yes, on the rubric's ruling for class-carried zips. `example.tex` defines no macro, counter or environment of its own: it passes options and strings to the class `eskd`, which is published (CTAN page `ctan.org/pkg/eskd` read: LPPL 1.2, v2004-10-12, in TeX Live). So an emitter writes `\documentclass[twoside,height=282,title]{eskd}`, the field commands and a plain body, with no copied macro logic. The picture-drawn frames live inside the published class, so they belong to `class.eskd` and are not counted as `ART`. The only caveat is a missing asset: the `pscyr` fonts that the class loads unconditionally (not on CTAN, not shipped).

## Blockers
none

## Class setting
- Class: `class.eskd` options: `twoside` `height=282` `title` (example.tex:2-4); `encoding=`, `year=`, `draft` exist and are commented out (example.tex:5-7). Defaults from the manual: twoside off, height 282 mm, title off, encoding koi8-r, year = current year (eskd.dtx:100-115). The class does `\LoadClass[a4paper]{article}` (eskd.dtx:255), so `class.article` is its base; `twoside` and `draft` are passed on to article (eskd.dtx:242-248).
- Class-native vocabulary used: stamp-field commands `\docName` `\docSignature` `\docLabel` `\middleLabel` `\docAuthor` `\docChecker` `\middleName` `\normController` `\approvedBy` (example.tex:10-18; short aliases `\fI` `\fII` `\fIX` `\fX` `\fXIi`..`\fXIv` at eskd.dtx:721-786); title-page commands `\titleTop` `\titleApprovedBy{post}{name}` `\titleAgreedBy{post}{name}` (3 calls) `\titleDesignedBy{post}{name}` (3 calls) (example.tex:22-31; defined eskd.dtx:793, 818, 836, 856); `\eskdListOfChanges` (example.tex:41; eskd.dtx:1020). Defined by the class and not used in the sample: `\titleName` `\titleSignature` `\titleBottom` (eskd.dtx:885, 892, 901), macros `\eskdheight` `\eskdencoding` `\eskdyear` (eskd.dtx:208-216). Internal page styles `common`, `first`, `title` (eskd.dtx:540, 615, 693).
- Dependencies the class loads unconditionally (eskd.dtx:234, 261-270): `keyval`, `inputenc`, `babel`, `fontenc`, `rotating`, `lastpage`, `ifthen`, `fancyhdr`, `pscyr`, `geometry`. `pscyr` is a font pack from ftp.vsu.ru (README:34-35); `ctan.org/pkg/pscyr` is a 404 and the eskd CTAN page says it is not (apparently) on CTAN. Missing asset: ship it. Not a blocker (fonts, not a tool outside TeX).

The class ruling above is the one place where the verdict is sensitive: the zip ships the class only as `eskd.dtx` source, but `ctan.org/pkg/eskd` shows the same class on CTAN and in TeX Live, so W1 holds and `class.eskd` is the way.

## Content-opaque
- `example.eps`, the figure artwork of the manual (eskd.dtx:121). The manual driver uses the `dvips` option (eskd.dtx:3); a pdfLaTeX build of the manual would need `fig.epstopdf` (EXTERNAL for that manual only). `example.tex` includes no image, so this does not touch the verdict.
- `\verbatiminput{example}` in the manual (eskd.dtx:130) prints the source of `example.tex`: code text.
